# PhysX 受控夹持与释放

[English](pinch.md) | [简体中文](pinch.zh-CN.md)

这个实验用两个理想棱柱关节夹指隔离接触行为：每侧向内施加 4 N，检验正常承重、过载、零摩擦和完全释放。它通过 UniSim 公共实体接口运行官方 PhysX，沿用已披露的接触报告适配补丁；不是机器人电机、SDF、圆柱或苹果抓取资格验证。

## 运行与复核

先按 [PhysX 安装](README.zh-CN.md) 配好 worker。每次使用新目录：

```bash
.venv/bin/python -m dexlab.physx_pinch run --case hold --output demos/physx-contact/runs/pinch-hold
.venv/bin/python -m dexlab.physx_pinch run --case overload --output demos/physx-contact/runs/pinch-overload
.venv/bin/python -m dexlab.physx_pinch run --case frictionless --output demos/physx-contact/runs/pinch-frictionless
# 离线复核不需要启动 Isaac Sim
.venv/bin/python -m dexlab.physx_pinch verify demos/physx-contact/evidence/pinch-v2/qualification-v2/hold
```

## 物理协议

两个固定根、单平移自由度的夹指，质量各 0.1 kg，解析碰撞箱半尺寸 5×25×40 mm，起始中心 x=±15.2 mm、z=200 mm。自由物体半尺寸为 10×10×30 mm；质量与摩擦由下表给出，惯量按均匀长方体计算。夹指禁用重力；物体重力为 9.81 m/s²。

步长 1 ms、总长 3.5 s，每个物理步保存实际关节状态、刚体位姿和速度、外力命令及两侧法向接触力。没有位置执行器或附着约束。前 0.5 s 仅用显式 +mg 外力支撑物体完成夹紧，随后撤去；这段准备不是自由夹持成绩。每侧 4 N 保持至 2.5 s；释放用 25 ms 向外 2 N、25 ms 反向 2 N 制动，然后撤力，避免持续驱动撞到行程末端。

| 条件 | 理想摩擦承载上限 | 重力 | 预期行为 |
|---|---:|---:|---|
| hold：0.2 kg、μ=0.3 | 2.4 N | 1.962 N | 保持，松手后下落 |
| overload：0.5 kg、μ=0.3 | 2.4 N | 4.905 N | 撤去准备支撑后滑落 |
| frictionless：0.2 kg、μ=0 | 0 N | 1.962 N | 撤去准备支撑后下落 |

`μ(N_left+N_right)` 仅用于平行竖直面、水平法向、无黏附及其他支撑的库仑假设；验收使用实际法向力读数，而不是仅信任施加命令。没有独立记录切向摩擦力；这里只检验承载/运动行为，不能声称完成全接触力账目或圆柱载荷曲线。

## 独立验收

评分器不启动引擎。它验证完整 3,500 步、时间网格、数据与源码哈希、原生质量/摩擦/自由度读回，以及实际关节读数与夹指位姿的一致性。用实际姿态和解析箱体的 15 条分离轴独立计算物体—夹指重叠，不使用 PhysX 自报的穿透值。

- 全程物体—夹指穿透小于 1 mm；棱柱位姿一致性为 1 μm，夹指转动矩阵误差为 1e-5。
- 0.52–0.60 s 的实际平均法向力各自偏离 4 N 小于 5%。正常承重在 0.7–2.5 s 漂移小于 1 mm、速度小于 5 mm/s，两指法向力持续大于 0.1 N。
- 两个负对照在撤去准备支撑后 200 ms 下落超过 50 mm；正确滑落记为物理测试通过。
- 2.8–3.5 s 法向接触力小于 0.01 N，释放后的下落超过 50 mm；速度拟合加速度与 −g 相差小于 2%，最大速度拟合残差小于 0.01 m/s。

这些是工程资格阈值，不是真机测量精度。测试注入释放后黏住、过载错误保持、隐藏支撑力、伪造夹紧力、接触中断/缺失、损坏时间与日志，确保评分器拒绝错误证据。

## 失败保留与边界

开发探针最初因 UniSim 不支持被动关节阻尼而在准备阶段失败；当前夹具明确采用零被动阻尼。第一轮正式夹具记录使用持续向外释放，过载案例因撞到行程末端时关节/连杆读数偏差 1.0058 μm 超过 1 μm 而失败。第二轮改为有限脉冲与制动，阈值不变；第一轮三项结果及原始轨迹全部保留。

[全部记录与哈希](evidence/pinch-v2/manifest.json)记录两轮结果；它们属于开发后的单案例资格验证，不是留出成功率或跨引擎排名。每轮源码随轨迹存档，旧轨迹应使用当时评分器复核，不能把新释放协议强加给旧日志。FP32 微小几何差值不能解释为真实硬件精度；计时包含 Python/IPC，非独占性能测量。
