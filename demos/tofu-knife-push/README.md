# 豆腐刀面推动 / Knife-driven tofu separation

[中文实验说明](../../docs/site/zh/tofu-comparison.md) · [English experiment](../../docs/site/en/tofu-comparison.md)

协议与原始记录分开保存：`protocol.json` 冻结输入和验收，`resource-amendment.json` 保留运行前的单次时间上限修正；`evidence.json` 收录四组结果、负对照、源码身份、成本与推动前状态一致性核验。媒体独立核验和可移植档案哈希分别见 `media-validation.json`、`archives.json`。

`protocol.json` freezes the physical inputs and acceptance; `resource-amendment.json` preserves the pre-half-step runtime-budget correction. `evidence.json` contains all four records, negative control, exact source identities, costs and pre-push equality checks. `media-validation.json` independently checks displayed values against raw arrays. `archives.json` identifies the portable release archives.
