# 法向阻尼配对消融

[English](DAMPING_ABLATION.md) | 简体中文

状态：六组预登记实验完成并独立复算，已在 [v0.28.0](https://github.com/huangkiki/Dexlab/releases/tag/v0.28.0) 发布。问题：同一配对中其余条件全部固定时，将 SuperDex 法向黏性系数置零，是否消除先前卸载阶段记录的负法向力？

[六组矩阵](../../benchmarks/contact-damping-ablation-v1.json)固定0.2kg、40mm方块、零摩擦、相同初始位姿与速度、原生BOX／平面表示、罚系数12,500,000、阈值1µm和平滑半距0.5µm。净向下载荷2／4／6／−1N各持续0.2s。在0.5／0.25／0.125ms三个步长下分别配对0／10s/m阻尼系数，交替配对内顺序。每组运行一次、串行执行，批次预算600s，服务强制时限660s；运行前检查官方最新版本与源码。禁止在线调参。

主问题的参照：无黏附接触不应产生拉拢两物体的力。保留原有1e−6N无拉力容差、动量／接触台账／几何／稳定／释放检查及全部失败。记录竖直接触力最小值、负力步数与时长、发生时间，区分加载和卸载。接触力在原生步进后读取、对应该步；状态数组包含初始状态。核对台账求和与动量，不仅凭运动反推力。

K=20kN/m、D=40Ns/m的常阻尼瞬态目标仍为单独标注的合成诊断，零阻尼不必满足它。如果零阻尼仍有负力，否定简单的“仅阻尼导致”解释；若负力消失，只支持此参数在该工况中的作用，不能证明内部接触律公式或普遍引擎缺陷。内部几何烘焙与完整组合律仍有不可观测项。确定性配对不支持总体置信区间；真实材料标定另行处理。

## 配对结果

六组原生运行完成，独立复算全部重现。三对的实际初态、输入网格、逐步外力、时钟、源码、原生版本／求解器与除阻尼外的 actor 参数一致；接触台账和动量检查通过。这只覆盖可读取的表示，不能冒充内部完整组合律读回。

| 步长 | 阻尼 0：最小法向力 | 阻尼 10：最小法向力 | 阻尼 10：负力步数／时长 | 零阻尼的工程验收 |
|---|---:|---:|---:|---|
| 0.5 ms | 0 N | −0.450712 N | 2／1.00 ms | 通过 |
| 0.25 ms | 0 N | −0.281743 N | 3／0.75 ms | 平台稳定性失败 |
| 0.125 ms | 0 N | −0.161407 N | 4／0.50 ms | 平台稳定性失败 |

负力全部出现在卸载段。零阻尼三组均无低于原容差的负力；非零阻尼三组均因无拉力检查失败。**在本配对工况中，将该参数置零消除了记录到的负力，但未取得完整修复。** 原工程验收只有1/6通过，结合原瞬态目标后0/6通过。零阻尼并不等于目标40Ns/m常阻尼，不能为了消除一个症状就声称完成材料标定。

## 逐接触点卸载诊断

离线扩展复用原来的六份冻结归档，没有新增动力学回合，也没有修改历史验收。`--pointwise` 先复现原报告，再检查每步接触点力之和、有限数值、原生向上法向和世界坐标 z=0 的平面侧接触位置。只有通过该水平平面资格后，竖直点力才作为法向分量解释；未知坐标系、缺行、力账本不一致均拒绝。1e-12 m／坐标检查针对序列化几何，不是物理准确性阈值；原 1e-6 N 拉力容差保持不变。

| 步长 | 阻尼 0：卸载期最小已观测点力 / N | 阻尼 10：最小点力 / N | 阻尼 10：负力点样本／涉及步数 |
|---|---:|---:|---:|
| 0.5 ms | 2.426e-9 | −0.075119 | 12 / 2 |
| 0.25 ms | 0.003374 | −0.046957 | 18 / 3 |
| 0.125 ms | 0.004274 | −0.026901 | 24 / 4 |

六组加载期均无负力点样本，零阻尼组卸载期也没有。该批记录中没有“局部存在负力但总力非负”的隐藏事件。这个结果补足原总力诊断的观测缺口，不代表修复了静置／瞬态失败。独立合成反例验证：一个正力点抵消负力点、使总力为正时，诊断仍能检出局部负力。

计数是每个求解步的接触点样本，不是具有持续身份的独立接触数量。无接触观测的窗口将最小点力记为 `null`，不编造零值。持续时间按涉及步数计一次，不能表示子步接触寿命。表中最小值不包含无接触步，与包含分离后零值的总力最小值不同。这是对已知数据的回顾性诊断，不是新预登记结果，也不能推广到任意曲面。

```bash
python demos/contact-benchmark/report_damping_ablation.py PATH_TO_STUDY --pointwise
```
