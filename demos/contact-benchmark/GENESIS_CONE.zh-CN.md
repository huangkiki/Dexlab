# Genesis 摩擦锥诊断

[English](GENESIS_CONE.md)

这是 #42 的阶段工作，研究基础盒体受到水平速度激励后的竖直瞬态，不代表 SDF 抓取、关节、GPU 批量、布料或真机精度通过验证。

官方 Genesis 1.4.3 / Quadrants 1.3.3，CPU FP64，种子 0，请求确定性模式。边长 50 mm、密度 1000 kg/m³ 的盒体先在平面上静置 0.5 s。两个材料的 μ 均为 0.5，重力 9.81 m/s²，步长 5 ms、子步数 1。Newton 约束求解器、approximate-implicitfast 积分器、25 次迭代，关闭 no-slip 后处理。完整配置随记录保存。碰撞几何是原生盒体与平面，不是 SDF-SDF。

每次重置场景，分别执行：不写速度、所有速度归零、设置 x 速度 0.5 m/s 并清零其他分量、只修改 x 速度。在金字塔和椭圆摩擦锥下各执行四种对照，逐步记录 0.2 s。条件参考为 vₓ=max(0.5−μgt,0)，假设平面接触与纯平移；转动会限制此参考的解释范围，当前没有实测材料参照。

## 初步测量

| 摩擦锥 | 首步法向力（N） | 首步竖直速度（m/s） | 最大参考速度偏差（m/s） |
|---|---:|---:|---:|
| 金字塔 | 6.142033 | 0.196631 | 0.098316 |
| 椭圆 | 1.226250 | 约 0 | 0.000879 |

这是此前本地诊断测量，公开原始数据交付与发布验证尚未完成。结果支持该场景存在与配置有关的瞬态，不构成引擎排名。不写速度与归零对照保持静止；两种水平速度写入方式产生近乎相同的瞬态。此前完整一秒、5 ms／高摩擦测试未满足预设 0.05 m/s 偏差阈值，仍保留为失败。另一次 μ=0 尝试被官方校验器拒绝（最小 0.01）；低摩擦不能称无摩擦。同机重置配对结果一致，跨机器确定性尚未验证。

## 复现

使用独立 Python 3.12 环境，安装 editable DexLab 与官方 `genesis-world==1.4.3`；测量使用 Torch 2.9.1+cpu。运行前遵循仓库有界执行与资源准入规则。安装成功不等于最新版本或原生文件来源校验通过，须保留软件包哈希证据。

```bash
python -m dexlab.genesis_cone_probe /path/to/new-output
python -m dexlab.genesis_cone_score /path/to/new-output
```

运行器拒绝覆盖旧目录，记录源码哈希、配置及全部八条轨迹，并保留异常。评分由独立标准库进程完成，缺帧或非有限值会报错，只报告偏差，不生成笼统的物理成功标志。构建／初始化、步进与观测分别计时；未渲染或归档，短 CPU 运行不属于吞吐基准。关节／夹持／释放、容量／隔离、连续录像及 GPU 验证仍未完成。
