# 接触起始瞬态的网格细化协议

[English](REFINEMENT.md) | [简体中文](REFINEMENT.zh-CN.md)

冻结的16次开发运行已完成，全部结果保留。既有半步长工况分别沉降，不能隔离积分误差。本实验改为每回合新建场景、无预沉降，测量接触起始瞬态；这是另一个明确声明的物理协议。

已执行矩阵固定质量0.2kg、半边长20mm、初速0.25m/s、重力9.81m/s²及0.5s时长。摩擦0.3和零摩擦对照分别使用1、0.5、0.25、0.125ms；双引擎共16次，最多600s。保留现有原生接触／求解器配置和物理验收，全部结果及物理失败均保留。

比较前核对归档完整性、物理设置、原生配置及实际初态。只比较共同物理时间，不插值；输出相邻网格间位置、速度和姿态的最大值与RMS差异。最细网格不是参考真值。Coulomb解析参考偏差单列，因为柔顺／正则化接触律不等于理想模型。

假设是细化后响应在所测范围趋于稳定。初态不匹配则拒绝比较；非单调或平台差异不能证明收敛阶。没有误差预算就不制造准确性通过阈值。内部接触历史并未独立观测。下方另做求解容差对照；仅缩小步长不能证明求解器收敛或真机准确性。

实现为 `dexlab.contact_refinement.compare_grids`。十项解析构造、混淆与归档负例测试通过，不计入原生回合。矩阵为 `benchmarks/contact-onset-refinement-v1.json`；运行前已冻结协议并完成官方版本准入。

实测：MuJoCo原工程验收8/8通过；SuperDex4/8通过，四个有摩擦瞬态全部失败。SuperDex1ms工况还违反动量平衡和无倾覆参考条件，较细步长仍违反Coulomb速度检查；不调参消除这些失败。全部12组归档的已声明原生配置和实测初态匹配，因此能比较轨迹，但这不等于物理验收通过。

正向工况相邻网格最大位置差（1→0.5、0.5→0.25、0.25→0.125ms）：MuJoCo为0.06117／0.03538／0.01539mm，SuperDex为1.47480／1.96621／1.24122mm。SuperDex零摩擦通过工程门禁，但差异增大到0.16408／0.29110／0.35495mm。因此通过验收和缩小步长均不能单独证明收敛。结论仅针对这些固定瞬态协议，不作引擎精度排名。各对比较的采样密度不同，不拟合收敛阶；下方容差研究检查其中一个混淆因素；接触起始机制仍未完全识别。

## 求解状态与成本

新增逐次运行明细包含16次实际初态、原生参数读回、文件哈希、独立评分和耗时。SuperDex 有摩擦1ms运行的首步为 `STOPPED`，其余499步为 `CONVERGED`；其余7次运行全部为 `CONVERGED`。因此不能把所有差异归因于达到迭代上限；原生收敛状态也不等于跨步长收敛。MuJoCo记录的是警告计数，不能将无警告包装成求解器收敛证明。

SuperDex读回为 backward Euler、100次迭代上限、绝对容差0.001、相对容差1e-6；各步长保持不变。容差敏感性尚未排除，下方对照独立改变求解容差并记录实际读回，没有同时重调接触参数。

批次内部墙钟27.203秒，包含子进程启动和版本准入。逐次 `step_and_observation_seconds` 包含步进及观测查询，不是纯求解器耗时；准备和总耗时另列。单次未重复计时，未形成性能排名。

## 求解容差受控对照

另行预登记的12次SuperDex实验保持接触、初态和100次迭代上限不变，在0.5/0.125ms下将绝对／相对容差从1e-3/1e-6同时缩小100倍与10,000倍。有摩擦和零摩擦各6次；所有步均报告 `CONVERGED`。有摩擦6次仍未通过原Coulomb检查，零摩擦6次通过。

有摩擦0.5ms下，原容差→严格容差最大位置差1.961µm，严格→更严格为0.01837µm；但跨步长最大位置差仍为3.20627／3.20621／3.20621mm。零摩擦对应跨步长差为0.554478／0.554495／0.554495mm。因此，在此范围收紧停止容差并未消除步长敏感性；不能把它简单归因于求解器提前停止，也不能据此指定另一个未经验证的原因。两种容差同时变化，尚不能区分各自贡献。

## 离线复算

安装DexLab的Python依赖并准备原始记录后，在仓库根目录运行：

```bash
python demos/contact-benchmark/report_refinement.py /path/to/onset-v1 --output /path/to/new-onset-report.json
python demos/contact-benchmark/report_solver.py /path/to/solver-v1 --output /path/to/new-solver-report.json
```

输出必须为输入归档之外的新文件。两条命令均不运行仿真；返回0要求全部比较与逐次明细完整，不代表物理通过。已准备原始归档，含28次记录、603个哈希文件及两批实验各自冻结源码。解包后28次原始评分逐字段复现；原生数据字节未修改。归档19,408,122字节，SHA256 `073dd8c48708b186313a9f522b491ab2cb8a8a673189fde8b0e1bb52e7cbcc5d`。当前仅本地准备完成，尚未成为公开发版附件。
