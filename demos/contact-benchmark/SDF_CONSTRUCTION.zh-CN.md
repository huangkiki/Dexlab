# 静态 SDF 构建路径可观测性

[English](SDF_CONSTRUCTION.md)

问题：官方预生成网格能否复现自动生成碰撞体的采样距离？这是几何构建问题，不是动态抓取或材料标定测试。

固定协议：闭合 40×30×20 mm 盒体，请求 2 mm 网格间距，静态原生 SDF actor，绕 z 轴旋转 0.7 rad、平移 [0.1,0.2,0.3] m。step(0) 后查询固定 9×9×9 内部点阵。比较两侧原生距离，并独立计算解析盒距离。保存完整显式生成网格和实际原生位姿。不使用边界外查询；官方 API 对边界外仅承诺距离上界。

1e-12 坐标比较容差仅检查 FP64 序列化配置，不是物理准确性阈值。采样是否完全相等与绝对偏差分开报告；证据完整可以支持负面结果。

```bash
python demos/contact-benchmark/probe_sdf_construction.py --output NEW_DIRECTORY --wheel-dir OFFICIAL_WHEEL_DIRECTORY
```

必须在仓库实测资源限制内运行。构建前核查官方稳定版与原生 wheel，输出必须为新目录。不修改苹果演示或引擎源码。预生成网格是官方生成函数的可观测输出，不是自动 actor 内部网格的直接读回。

最初私有开发探针：显式网格 27×22×17，共 10,098 值；729 个距离最大差异 0.129771 mm。相对解析盒的最大偏差分别为自动路径 0.273479 mm、预生成路径 0.293555 mm。这些初步记录采用请求位姿；可复现程序额外读取实际位姿，实际位姿资格验证见下文；公开证据交付仍待完成。没有更多证据前不将差异归因于某个算法。

## 新版运行证据

已完成一次新版静态运行：读取两侧实际位姿并验证相同，729点差异与初步记录一致，10,098网格值完整保留。源码冻结检查通过；独立离线程序重算结果一致。它验证记录完整性和差异，不把不等价改判为准确性通过。[结果](../../docs/evidence/sdf-construction-v1.json)

```bash
python -m dexlab.sdf_observability RECORD_DIRECTORY
```

程序先校验原始数组、报告和源码快照哈希，再重算解析参考及最大差异。缺测、被篡改报告或不合法路径均被拒绝。公开证据附件与完整交付验收待完成。

离线评分器还核对保存的网格维数、数值数组形状、有限边界、间距与封闭盒体输入网格，确认其符合声明的几何。这只验证表示一致性，不验证插值精度或自动构造路径的隐藏网格。

## 已验证的证据包

本地已验证的 `dexlab-sdf-construction-v1.tar.gz` 含 128 个有哈希记录的文件（370,217 字节），包括未改动的原始数组、冻结的运行源码与单独的最终评分器。解包与离线复算一致。SHA-256：`71e46662e788d1cf820f8d6ae3fa2dd14b61fa9ccbf7cc008f966357cb80fce1`。公开发布仍须完成仓库验收。

此前完整读回自动碰撞体内部烘焙网格的目标，**没有被显式烘焙输出满足**。已测静态记录路径也未导出该网格。采样不等价的结果排除了把显式网格当作可互换读回的做法。同样，文档中的参数组合律不等于实际逐接触参数的测量。这些可观测性限制继续明确记录在 Issue #10；此证据包不代表整个接触诊断任务完成。

## 发布期间的运行时迁移

MuJoCo 3.15.0 在原 3.14.0 交付验收期间发布。3.14.0/SuperDex 两条抓取独立评分均通过，但最新稳定版准入拒绝了该环境；失败记录保留。独立 3.15.0 环境通过全部 486 项测试及官方 wheel／已安装代码身份核验；旧 3.14.0 兼容回归也通过 486 项测试。3.15.0 完整抓取发布验收仍待完成。

显式候选配置不授予正式准入。3.15.0 的布料 XML 省略已删除的 `internal` 属性，弹性布料适配器继续使用 3.14.0 已采用的 `discrete` 积分器；旧配置保留其 XML 和积分器。首次测试有五个 XML 错误，修复后又暴露两个未选择 discrete 配置的错误，两轮失败均保留。这些只是接口修复，不证明布料动力学不变，也不构成新布料基准。参见[官方发布说明](https://github.com/google-deepmind/mujoco/releases/tag/3.15.0)。

静态 SDF 证据包保留原运行源码与单独评分器，不重写成新运行时生成的记录。
