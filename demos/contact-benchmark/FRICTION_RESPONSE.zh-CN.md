# 摩擦响应诊断

[English](FRICTION_RESPONSE.md) | [简体中文](FRICTION_RESPONSE.zh-CN.md)

**两个引擎均通过八个已声明开发工况，但低速接触合力响应不同。** 现有平面评分器将完整轨迹与不倾倒的理想库仑滑动比较。新增只读诊断按实际质心速度整理实测接触合力，不修改原评分器和冻结验收阈值。

每次已完成求解使用其前后记录的平面质心速度中点 `v_mid`。法向合力 `Fz` 为正时，计算有符号阻力比 `−Ft·v_mid / (|v_mid| Fz)`。正值表示阻碍平移，负值表示助推。这是力比，不是识别出的静摩擦系数。原生受力与积分后状态的时刻不同；中点配对是一项明确的时间近似。

速度区间下界为 0.0001、0.001、0.01、0.05、0.1 和 0.3 m/s，末区间无上界。法向载荷低于体重 1%、速度低于下界或步前后速度方向相反的样本不参与力比计算。保留互斥排除计数及区间时长；空区间为 null，不填零。这些是诊断划分，不是新成功阈值或实测材料参数。

缺失接触覆盖时诊断不完整。即使能绘制响应，动量、穿透或参考适用性失败仍保留失败。倾倒或非平面运动不满足平面参考假设。`Σ Ft·v_mid Δt` 仅为平移接触功代理量，忽略转动、接触点运动与原生摩擦锚点，不能称为材料点滑移或总摩擦耗散。

```bash
.venv/bin/python -m dexlab.contact_friction runs/contact-plane
```

命令读取并独立复核已有归档，输出 JSON，归档验收失败时返回非零；不启动物理、不覆盖记录。旧引擎结果保留历史标记。新增成对开发实验需通过官方版本准入、冻结输入并受限执行；摩擦/材料等价性、烘焙几何及正式成本—误差比较仍在 #10 跟踪。

## 冻结开发结果

![原生摩擦诊断及全部工况速度误差](media/friction-response-v1.png)

曲线点是在速度区间几何中心展示的区间中位数；连线仅辅助阅读，不是拟合本构。空区间不填值。右图包含全部 16 次运行及零摩擦、静止控制。没有丢弃失败原生结果：16 次均通过原平面验收，离线重评逐一重现。缺接触、助推力、换向及倾倒等合成负例是独立单测，不算原生回合。

[冻结矩阵](../../benchmarks/contact-friction-v1.json)采用 MuJoCo **3.14.0** 与 SuperDex **1.0.0 FP64**，执行前核验官方 wheel、实际加载原生身份及最新稳定版元数据。八组成对配置为正反向 0.25 m/s、正反向 0.005 m/s、零摩擦、静止、0.4 kg 质量和减半步长。默认质量 0.2 kg、系数 0.3、步长 0.5 ms、沉降 0.2 s、测量 0.5 s。未在查看结果后拟合参数。这是开发证据，不是留出标定。

| 观察量 | MuJoCo | SuperDex |
|---|---:|---:|
| 正向：1–10 mm/s 区间阻力比中位数 | 0.15641 | 0.02076 |
| 低速初态：同一区间 | 0.10405 | 0.02320 |
| 正向最大速度参考误差 | 4.877 mm/s | 2.954 mm/s |
| 减半步长最大速度参考误差 | 3.779 mm/s | 3.285 mm/s |
| 默认工况原生沉降后初始质心高度 | 19.996671 mm | 20.063331 mm |

较高速正向区间的阻力比接近名义 0.3。低速响应受原生接触定律及区间内部速度分布影响；中位数不是相同速度上的本构采样。减小步长并未一致改善误差。MuJoCo 名义零摩擦运行仍记录约 0.00001 阻力比，SuperDex 接近零，报告保留这一差别，不舍入成完全等价。实际沉降初始高度不同，没有靠位姿对齐隐藏。这些实验不能判断哪个引擎更符合真实材料。

[全部逐工况结果](evidence/friction-response-v1.json)包含实际初态、原生读回、源码与产物哈希、排除计数、评分及成本。含官方准入的整批墙钟为 27.492 s。MuJoCo / SuperDex 准备时间范围为 0.091–0.105 s / 0.298–1.189 s，步进加观测为 0.059–0.094 s / 0.131–0.242 s。这些包含不同观测开销与步数，未排除任何工况，**不是隔离的原生求解器吞吐对比**。物理运行不渲染，报告绘图另行执行；未采集真机数据。

使用已准入官方环境及已有 wheel 缓存，在仓库受限执行器内指定新输出目录：

```bash
python demos/contact-benchmark/friction_response.py runs/friction-new --wheel-dir "$OFFICIAL_WHEEL_DIR"
python demos/contact-benchmark/report_friction.py runs/friction-new --output runs/friction-report.json --plot runs/friction-report.png
```
