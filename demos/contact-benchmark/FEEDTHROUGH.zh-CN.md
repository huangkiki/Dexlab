# 外加载荷影响与材料响应的区分

[English](FEEDTHROUGH.md) | [简体中文](FEEDTHROUGH.zh-CN.md)

**实测结论：** MuJoCo 低阻抗9组通过冻结的数据有效性检查，高阻抗9组全部未通过稳定性检查。拟合残差再小，也不能把后者变成有效的材料辨识。这是合成场景的开发实验，不是真机标定或引擎排名。

![有效性、预测与时刻诊断](../../docs/evidence/feedthrough-v1.png)

| 固定配置 | 有效 / 声明运行 | 有效的步前拟合 | 限制 |
|---|---:|---|---|
| `solimp=0.001`，`solref=-24975 -49.95` | 9/9 | K≈19920.239 N/m；D≈39.84048 Ns/m；外加载荷增益≈0.00398804 | 仅为局部响应，不证明全局材料等价 |
| `solimp=0.9`，`solref=-2500 -5` | 0/9 | 不予验收 | 0.4秒后速度与高度波动仍未达稳定要求 |

有效组增加载荷项后，对较小幅度力记录的最大预测 RMS 为2.19e-15 N。这是数值一致性，不是测量不确定度。工程参考仍为 K=20000 N/m、D=40 Ns/m、零直接载荷增益；此前瞬态、迁移和卸载失败保持原判定。低阻抗的基础模型也达到本次预测容差；扩展模型残差更小，不代表已证明实际精度显著提升或学出了控制器。

## 研究问题与冻结协议

[实验前登记](https://github.com/huangkiki/Dexlab/issues/10#issuecomment-6016384683)：弹簧阻尼拟合是否混淆了外加载荷的直接影响？同时拟合 `F = a + K*压入量 + D*向内速度` 与增加 `alpha*外加载荷` 的模型。MuJoCo [官方近似标量约束模型](https://mujoco.readthedocs.io/en/stable/modeling.html#solver-parameters)是问题依据，并不直接证明四接触耦合关系。

- 官方 MuJoCo3.15.0，Euler/Newton，100次迭代、容差1e-10；批次冻结时核对官方稳定版与 wheel 内实际二进制，不改引擎。
- 自由0.2 kg、40 mm方块，零摩擦，重力9.81 m/s²；质心施加包含重力补偿的向下载荷。记录实际原生状态和力，不覆盖姿态或加入伺服。
- 沿用既有响应成本实验的两种配置；先高后低阻抗，步长按0.5/0.25/0.125 ms递减，预载按2/4/6 N递增，共18个全新场景串行运行。
- 每次1.2秒：0.4秒稳定，0.4秒20/35 Hz双频激励（每个频率幅值为预载2%），随后0.4秒降为1%。验证延续同一轨迹，不称独立重复或总体留出集。
- 回归中心化、标准化、满秩且条件数≤20；拟合与验证 RMS≤单频幅值5%。沿用原切线辨识检查：动量残差≤1e-5 N、力记录差≤1e-7 N、稳定速度≤1e-5 m/s、高度标准差≤1e-6 m、载荷平衡误差≤1%、纯法向运动与持续接触。均为工程诊断阈值，不是实测材料容差。
- **步前状态**对应预先指定的求解力时刻；步后结果单独报告，不择优。18组动量残差均≤6.00e-11 N，但不能据此豁免高阻抗稳定性失败。

## 复现与审计

在有资源硬限制的实验环境中，显式使用 MuJoCo 资格配置：

```bash
DEXLAB_MUJOCO_PROFILE=qualification-3.15.0 python -m dexlab.contact_feedthrough_run NEW_DIRECTORY
python demos/contact-benchmark/feedthrough_report.py RECORD_DIRECTORY --output REPORT_DIRECTORY
```

第一条需要官方引擎，第二条不导入引擎，从完整状态与逐步接触记录复算。外部稳定版、官方 wheel 与资源准入仍须执行；运行器自身不提供资源限制。诊断耗时包含读回和 I/O，不是性能基准。

[全部18组独立复算](../../docs/evidence/feedthrough-v1.json)保留无效工况和两种时刻；[图表溯源](../../docs/evidence/feedthrough-v1.provenance.json)绑定绘图数据。原独立驱动、源码快照、接触原始记录及全部失败保留。集成验收器重新计算回归，不信任已保存判定。6项新增测试覆盖已知系数、激励不足、预测良好但未稳定、时刻差异、相干力注入，以及归档、参数和警告篡改。没有重跑原生轨迹来制造成功记录。

另用低阻抗4N/0.5ms工况检查集成运行器：全部状态数组、原始接触行与独立评分均和原记录完全一致。这是18组之外的实现复现检查，不新增成功样本。

Issue10仍开放：共同材料标定、卸载行为、不可观测的配对参数尚未解决；真机测量属于Issue6。本报告为下一版本准备，发布状态仍须单独核实。
