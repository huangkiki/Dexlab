<h1 align="center">DexLab</h1>
<p align="center"><strong>Agents and simulation, improving together through experiments.</strong></p>

DexLab is my personal research project on robotic manipulation and physics simulation: learning from task failures and using controlled experiments to improve skills and simulation models.
