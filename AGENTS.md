## Research and evaluation policy (2026-10-08)

- Mission: use established physical laws and empirical relations in reproducible experiments to study contact/friction in robotic grasping and assess simulation reliability. README leads with findings, conditions, evidence and the documentation link; unfinished work belongs in Issues, never presented as results.
- Separate analytical numerical verification, sourced empirical references (units, conditions, uncertainty), and real-system validation. The first two do not wait for hardware #6 and do not establish arbitrary real-material or robot accuracy. Literature properties are not measured project parameters; screenshot numbers or improvement ratios are not acceptance references.
- Before every new evaluation freeze the full matrix: MuJoCo, SuperDex, Genesis, Newton Physics, PhysX, Drake and applicable registered solver profiles. Execute every qualified applicable cell; retain passed/failed/blocked/unsupported/not-run with evidence, linked Issues and recovery conditions for gaps. Never silently omit engines or count frameworks as engines. Incomplete coverage cannot be called a completed all-engine comparison; explicitly scoped interim evidence may ship. Preserve historical cohort scope.
- Record engine, native core, binding/framework versions separately from solver algorithm, integrator, contact model, precision, CPU/GPU, timestep, iteration/tolerance budgets and parameter readbacks. Missing values remain explicitly missing and link to a resolution Issue, never inferred defaults; host versions are not PhysX versions. Newton Physics is distinct from a Newton solver algorithm; ManiSkill/UniLab/UniSim are not additional independent physics engines.
- Qualify official latest-stable compatible versions and freeze source/binary hashes before a batch. No engine patches, silent downgrades or relaxed thresholds. Reuse verified protocol-compatible evidence before new runs. Match units, frames, mass/inertia, geometry, initial states and inputs; equal numerical parameters do not establish contact-model or material equivalence.
- Freeze equations, assumptions, metrics, thresholds, windows, cases, budgets and parameter sources before outcomes. Distinguish static-friction inequalities from sliding acceleration; collision references declare restitution, rotation and external impulses, without assuming a unique analytical solution for complex multi-body contact. Report absolute errors, convergence/sensitivity, cost, uncertainty and all failures; never cherry-pick or report only ratios, and never substitute better force residuals for grasp retention.
- Separate native observations, control commands, state playback and independent scoring. Record force/impulse epochs, missing contact signals and unobservable parameters. Playback is not physical success, rendering is not visual control, analytical verification is not hardware calibration. Each new comparison updates README with actual engine/solver/version/evidence scope.
- Put new worktrees, environments, caches and large outputs on configured mounted data; symlink routing alone is not migration of old data. Recover live handles, keep one worker and freeze its environment. Measure local admission, enforce cgroup memory/CPU/tasks/runtime with swap disabled and desktop headroom; serialize timing against transfers/large hashing. Delete originals only after hashes, offline reads and no-consumer checks; same-disk copies are not independent backups.
- Preserve uncommitted work and failures. Atomically maintain a private handoff, preferably at most120 lines; no credentials or public deployment paths. Obsidian commit/push remains paused. Notify only on deliveries, important regressions or required user input, not unchanged routine status.
