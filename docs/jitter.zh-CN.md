# 抖动与接触间断诊断

[English](jitter.md) | [简体中文](jitter.zh-CN.md)

离线分析器读取已有的逐物理步记录，不运行控制器、不推进场景、不改变引擎参数，也不替代抓取验收。

## 运行

完成[安装](installation.zh-CN.md)，取得完整或中断的运行记录后：

```bash
.venv/bin/python -m dexlab.jitter demos/apple-stem-grasp/runs/latest-mujoco-sdf
.venv/bin/python -m dexlab.jitter demos/apple-stem-grasp/runs/latest-superdex-sdf
```

命令在运行目录生成 `jitter-diagnostics.json`，并打印相同 JSON；`--output path.json` 可改变输出位置。输入文件只读。命令正常退出表示已生成报告，不代表抓取或数据质量通过。档案结构损坏会报错；记录不完整则保留在报告中。

输入包括 `engine.json`、`sdf-dynamics.npz` 和存在时的 `sdf-contacts.npz`。MuJoCo 还需要匹配的原始 `model.mjb` 或无损模型档案解析刚体 ID，只加载而不步进；SuperDex 的 ID 从 `engine.json` 读取。需要本地完整运行产物，只有打包的简要验收结果不够。报告记录输入文件与分析器源码的哈希，不依赖单独开发的模型审查功能。

## 信号、单位与定义

默认保持窗口为 **[11, 14) 秒**。采样来自 `engine.json`：当前 MuJoCo 为 2,000 Hz，SuperDex 为 500 Hz，与视频帧率无关。报告列出预期、唯一、缺失和重复样本，偏离网格的时间戳、观测间距与连续未知区间。两个记录器均使用物理步开始时刻标记行；位置/速度在积分后读取，接触力对应刚求解的这一步。

| 信号 | 定义 | 单位 |
|---|---|---|
| `apple_origin_world_position` | 世界坐标中的苹果刚体原点位置 | m |
| `apple_origin_wrist_relative_position` | 实际腕部坐标系中的苹果原点位置 | m |
| `apple_com_world_velocity` | 记录的苹果世界坐标线速度/质心速度 | m/s |
| `hand_force_on_apple_world` | 右手作用于苹果的世界坐标合力 | N |
| 各指腹 `load` | 该指腹所有已记录接触点的力向量模长之和 | N |

对于有限的已观测向量样本 `x`，`mean_components = mean(x)`，`rms_norm = sqrt(mean(||x||²))`，`peak_norm = max(||x||)`。去均值指标对 `x - mean(x)` 使用相同公式。标量指腹载荷采用单分量。原始力 RMS 包含支撑载荷，去均值力 RMS 才描述围绕该载荷的变化。位置变化包含缓慢漂移，没有去趋势、频率滤波、频谱估计，也不代表材料点累计滑移。

统计在声明的固定步长下等权计算。缺失、重复、结构错误或非有限样本被排除，不插值、不补零；每个信号给出有效/未知数量。完全没有观测时指标为 JSON `null`。不完整样本的统计可能有偏差，必须连同覆盖情况阅读。

## 接触间断与不可用数据

现有验收器要求两指腹各自的接触点力模长之和，在保持期始终大于 **0.1 N**。诊断沿用此边界，报告观测到的、不超过该值的连续采样区间。这表示低载荷支撑，不证明几何分离，也不引入新的通过/失败规则。

- 显式记录且有效的零力行，才计为观测到零载荷。
- 缺失物理步或没有该指腹接触行，记为**未知**，不计零。稀疏接触日志没有逐指完整性标记。
- 接触向量与独立记录的手部合力对账，使用验收器的 `atol=1e-8 N`、`rtol=1e-5`。不一致或接触字段无效会让该步两指均为未知。日志缺失或接触时间戳无法分配时，全部接触采样不可信。
- 多个接触点按指腹和物理步汇总。载荷求模长之和，对账求向量和，因此相反方向的力不会被误计为零夹持载荷。
- 未知采样会切断低载荷区间。区间贴近未知采样或窗口边界时，标记该侧被截断。时长等于观测样本数乘 `dt`，不是精确连续事件时刻。总低载荷时长上下界分别将未知采样视为高载荷和低载荷；它们只约束采样区间，不证明子步接触连续。

对账无法识别所有合力恰好抵消的记录遗漏。即使覆盖完整，也依赖记录器未被破坏。SuperDex 日志的法向力列是占位值，不据此生成法向力诊断。

## 能量边界

这些记录的 `energy.available` 为 false。完整能量收支还需要全系统速度/惯量、执行器做功和耗散/接触能量，现有记录不足。包含驱动、摩擦与阻尼的系统不能假定机械能守恒；动量平衡通过不等于能量守恒。

## 基线观测与验证

2026-09-29 对现有 `unilab-mujoco` / `unilab-superdex` 默认运行记录离线分析，得到下列去均值指标。两者沿用不同步长、摩擦与驱动的基线任务配置，不构成受控的引擎精度或速度排名。

| 保持期指标 | MuJoCo 3.11.0 | SuperDex FP64 1.0.0 |
|---|---:|---:|
| 唯一 / 预期样本 | 6,000 / 6,000 | 1,500 / 1,500 |
| 腕部相对位置 RMS / 峰值 | 0.07858 / 0.14479 mm | 0.01151 / 0.02367 mm |
| 质心速度 RMS / 峰值 | 0.17056 / 0.80133 mm/s | 0.00942 / 0.03141 mm/s |
| 手部合力 RMS / 峰值 | 0.007534 / 0.047451 N | 0.000167 / 0.000460 N |
| 观测低载荷时长，拇指 / 食指 | 0 / 0 s | 0 / 0 s |
| 未知接触采样，拇指 / 食指 | 0 / 0 | 0 / 0 |

测试覆盖静态支撑、解析振荡、平滑漂移、显式零力、阈值相等、缺失/重复/偏离网格的物理步、不完整接触日志、无效值、多接触点、坐标变换及输入不被修改。这些测试验证测量行为；完整物理验收仍由独立 [SDF 验收器](../demos/apple-stem-grasp/src/verify_sdf_grasp.py)完成。提交流程仍按原阈值运行两个后端完整 14 秒抓取。
