# 双引擎斜面解析对照协议

[English](incline-comparison-protocol.md) | [简体中文](incline-comparison-protocol.zh-CN.md)

比较官方 MuJoCo 3.15.0 与 SuperDex 1.0.0 FP64 对同一自由方块的响应。复用 #95 已发布的九个 impedance=0.9 记录；新增九个 SuperDex 记录。40 mm、64 g、均匀立方体，重力 9.81 m/s²；初态静止，底面贴合斜面，无控制器或初始化后状态写入。三个步长 2、1、0.5 ms，每例 2 s。

[冻结清单](evidence/incline-comparison/manifest.json) 保留 #95 全部阈值：15°、μ=0.5 静止，35°、μ=0.5 滑动，15°、名义 μ=0 滑动。静摩擦参考 |f|≤μN、tanθ≤μ；无翻转、连续接触的滑动参考 a=g(sinθ−μcosθ)。完整来源和假设沿用[原协议](incline-friction-protocol.zh-CN.md)。

接触参数不等价：MuJoCo 使用原始 solref、solimp；SuperDex 使用已发布的原生 penalty 参数、固定摩擦平滑速度与 contact_tangent_run 的 1e-9 绝对/相对求解容差。不得针对结果调参。相同 μ 不是实测材料标定；SuperDex 只能读回 actor 参数，不能假造组合接触律。报告该可观测性缺口，运动和力误差独立报告。

运行前零步核验几何、坐标、四元数顺序、质量、惯量、接触参数、求解器和初态。MuJoCo 力对应积分前求解，SuperDex 力对应已完成步骤；二者分别绑定产生该速度变化的时间区间。记录全部姿态、速度、力、接触距离和求解状态。使用原始 1e-7 N·s 冲量一致性界限；不满足者保留为无效记录，不修饰成物理准确度结论。

原始阈值、绝对误差、接触丢失、旋转及三个步长全部公开；参考假设失效与数值记录失效分别说明。只讨论这两个固定数值配置，不推断普遍引擎优越性。已有 MuJoCo 计时为历史证据，新记录分开记录准备、步进、观测成本，不给出速度排名。受限串行运行，首轮限九例，保留失败，后续事项见 #113。
