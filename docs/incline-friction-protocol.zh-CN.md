# 斜面摩擦：预登记解析评测

[English](incline-friction-protocol.md)

本协议对应 #95，目前只冻结实验设计，不宣称已得到结果。[固定清单](evidence/incline-friction/manifest.json)包含全部18工况，不依赖新增真机测量。

## 参考与假设

[OpenStax摩擦模型](https://openstax.org/books/university-physics-volume-1/pages/6-2-friction)给出静摩擦界限μsN及滑动摩擦近似μkN。由此推导不转动刚体方块的静止条件tanθ≤μs，沿坡加速度a=g(sinθ−μk cosθ)；无摩擦对照为g sinθ。μ=0.5是人为选定的模型输入，不是本项目材料的实测值。本实验量化相对理想响应的偏差。

自由方块边长40mm、质量64g，均匀惯量各轴mL²/6，初始底面恰与无限平面相切、姿态平行、速度为零，重力9.81m/s²。没有限制运动的关节、执行器或其他外力；初始化后不覆盖状态。世界坐标法向为(sinθ,0,cosθ)，下坡切向为(cosθ,0,−sinθ)。转动超过预定界限时，不转动参考失效，仍保留该失败。

## 原生语义和工况

官方MuJoCo3.15.0，包与原生版本一致，记录运行时哈希、模型XML及编译后读回配置。自由关节、解析方块/平面、condim3、Newton100次迭代、容差1e−10、Euler积分、椭圆摩擦锥、impratio1。两几何体滑动摩擦系数相同，无扭转/滚动摩擦，接触参数相同；从原生接触读回实际配对系数。单一滑动系数不能分别辨识μs与μk。

MuJoCo使用[软约束和接触参数](https://mujoco.readthedocs.io/en/stable/modeling.html#solver-parameters)。固定solref=(0.02,1)，分别测试恒定阻抗d=0.9和0.99，solimp=(d,d,0.001,0.5,2)。这些是数值设定，不是拟合材料。各自测试h=0.002、0.001、0.0005s；时间常数始终大于2h。固定接触参数的时间细化与接触参数敏感性分别呈现，不能把残余模型偏差都归因于积分误差。

三种工况：15°/μ0.5静止、35°/μ0.5滑动、15°/μ0无摩擦，共3×2×3=18工况；避开临界等式及理想倾覆边界。每例2s，评分窗0.5–2s，并报告从初始时刻开始的全部位移，不因去掉暂态而隐藏启动误差。不能把确定性工况当成统计成功率样本；看到结果后不调参。

## 观测与验收

每步保存时间、实测位置/四元数、线角速度、方块原生合接触力、距离/摩擦系数和警告计数。力属于积分前的求解时刻，显式保留其时间，不在步进后用mj_forward重新计算；位置速度属于积分后。保存源代码、配置、运行时哈希及全部数据。

评分窗以首个实测s0,v0为起点，对比v=v0+aτ及s=s0+v0τ+aτ²/2；同时报告全程从初始静止出发、未经重新锚定的参考误差，分别观察稳定滑动与启动阶段。对速度时间序列做最小二乘加速度拟合。静止漂移以原始初始位置为基准，另报评分窗最大速度。记录姿态变化、最大穿透、相对mg cosθ及库仑/静止支撑参考的法切向力残差，并按求解时刻核对离散冲量平衡mΔv−(F+mg)h。

预定工程容差（不冒充教材保证的通用精度）：静止漂移≤1mm、速度≤1mm/s；滑动速度RMSE≤0.01m/s、位置RMSE≤0.01m、加速度误差≤0.05m/s²；姿态变化≤0.01rad、穿透≤1mm、参考力RMSE≤0.01N。逐指标报告并给出联合判定，失败后不放宽。缺失、非有限、截断、时间/坐标/单位错误和检测到的状态注入均拒绝；评分器无法单独排除任意恶意伪造，来源还依靠源码审查和冻结原生执行证明。

发布全部18工况及误差—成本曲线，包括不单调细化和失败。分开准备、原生步进、观测及完整墙钟时间，不含渲染。单个资源准入执行者，每次最多30分钟，使用已有cgroup内存/CPU/任务数/零swap/I/O限制；测速期间无传输或大校验。重跑必须说明具体缺陷，使用新的不可变证据目录，保留旧失败。

## 结论范围

首个引擎建立基线，不作排名。评测说明设定的摩擦是否按预期承载或加速标准物体，以及数值选择如何改变响应。抓取还依赖接触法向、实际法向力和几何，斜面结果不能单独验收机器人控制器、任意真实材料或完整抓取。后续再独立扩展中心一维碰撞、恢复系数、守恒与对称性，并逐项核验参考假设。
