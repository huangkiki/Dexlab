# 标准方块夹持：承载与滑移协议

[English](pinch-load-protocol.md) · [冻结清单](evidence/pinch-load/manifest.json) · Issue #107

## 问题与参照

对称夹紧命令是否真正产生预期的承载能力和滑移？本任务是导向双夹面与自由方块的夹持夹具，不是真机控制策略或材料标定。全部18例均须执行，目前没有运行本研究的物理实验，结果待验证。

[OpenStax摩擦模型](https://openstax.org/books/university-physics-volume-1/pages/6-2-friction)给出|f_s|≤mu_s*N、|f_k|=mu_k*N。本研究mu_s=mu_k=0.5是合成设计值，不代表某种材料的实测值。对称、不旋转、两侧持续接触时，mg≤mu*(N_left+N_right)允许静止。每侧命令N_command=R*mg/(2*mu)，只有实际法向力等于命令时R=1才是理想临界。R=0.5预期向下加速度g*(1−R)，R=2预期保持；R=1是边界诊断，不给稳健保持通过结论。库仑近似及夹具条件限定了预测范围。

## 原生配置与控制

官方MuJoCo3.15.0 CPU FP64；Euler、Newton100次、容差1e-10、椭圆摩擦锥condim3、impratio1、solref(0.02,1)，恒定阻抗0.9/0.99，步长2/1/0.5ms，R=0.5/1/2，共18例。查看结果后不调参，不修改引擎。[官方驱动说明](https://mujoco.readthedocs.io/en/stable/computation/index.html#actuation-model)与[接触模型](https://mujoco.readthedocs.io/en/stable/modeling.html#contact)区分电机输入与实际接触响应；柔顺接触可能不满足理想模型条件。

方块质量64g、边长40mm、均匀惯量，六自由度，初始位于原点且静止。两个100g夹面为半尺寸(0.01,0.1,6)m的盒体，中心(±0.03,0,0)m，内侧表面初始触碰方块；高度覆盖一秒自由落体，没有地面或额外支撑。每侧只有朝内水平滑动关节，无限位、阻尼、关节摩擦或armature，单位gear力电机。夹具限制夹面其他自由度，这不是完整机器人动力学。仅允许夹面与方块接触，出现其他接触则判无效。

全局重力为零，0–0.5s不给方块外载，明确属于预加载辅助。夹紧力在0–0.2s线性升至N_command，之后恒定；0.5–1.5s在方块质心施加向下mg（方块等效重力，夹面重量由导轨承担）。以整数步索引定义斜坡与加载开始；不重置、不控制方块位置、初始化后不写状态。公开完整预加载及加载轨迹。

## 观测与独立评分

逐区间保存命令、实际电机/广义驱动力、方块外力、求解时间、每侧世界坐标接触力与接触位置/法向/摩擦/距离、广义接触力、警告及积分后状态。mj_step后的接触力属于积分前求解时刻，读取前不能再forward。保存编译后的物体/关节/几何ID、几何/质量惯量/求解器/接触/驱动字段，XML、完整轨迹、元数据、运行时/源码/清单哈希及全部耗时。哈希和压缩在计时步进之外进行。

独立区分：①命令载荷的理想预测；②实测法向力的摩擦容量诊断；③离散冲量/位置一致性。②使用实测力，不能标成独立预测；③不代表物理真实。独立汇总接触力检查方块平动及每个夹面的水平动量，不能仅依赖qfrc_constraint。方块各平动方向m*delta_v=h*(contact+external)，Euler为delta_x=h*v_next。记录旋转与接触力矩；平均竖直加速度正确不能覆盖双侧失联、横向漂移或旋转。

运动误差窗口t≥0.6s，以0.5s加载开始的实测状态为基准，并另报初始静止理想参照。R0.5比较恒定加速度预测的加速度、速度及位置；R2评分整个加载阶段的位移与最大速度；R1报告同样诊断但不作物理通过结论。报告每侧法向命令误差、原生摩擦界、双侧接触丢失、穿透、旋转、横漂、预加载速度及实际加载初态。保留整个阶段和评分窗口指标，包含0.6s前的失败。

## 冻结工程阈值与预算

阈值是前瞻研究容差，不是硬件不确定度：静态位移1mm、速度1mm/s；滑动速度RMSE0.01m/s、位置RMSE0.01m、加速度误差0.05m/s²；旋转0.01rad、穿透1mm、横漂1mm；每侧法向命令相对RMSE5%；加载阶段双侧接触丢失率0；力平衡RMSE0.01N。离散冲量残差1e-9N*s、位置更新残差1e-10m、摩擦锥余量1e-8N、加载开始速度≤1mm/s。清单固定全部值，不因失败放宽。运动拟合与参考假设分别判定；R1即使全部指标满足也只作为临界诊断。
