# UniCross：参考调研与 DexLab 的增量问题

**核查日期：2026-10-11。状态：仅参考调研，未实现、未通过实验验收。** 本文不启动跨引擎批次、不改变既有优先级，也不恢复定时开发。

## 来源身份与阅读深度

参考：Hui Zhang、Julian Ferchow、Jie Song、Mirko Meboldt，*UniCross: Unified Cross-Skill Dexterous Manipulation Synthesis*，[arXiv:2607.28198v2](https://arxiv.org/abs/2607.28198v2)，2026-10-07 更新；[官方项目页](https://zdchan.github.io/UniCross/)。

本次核查项目页及 arXiv 摘要／元数据，没有完成论文全文或实现源码审查。作者描述了抓取、搬移、手内旋转、手内平移的共享手物关系表达，以及逐手型统一策略的技能组合。项目页还描述 Isaac Gym、Isaac Lab、mjlab 实现，但核查时代码入口仍标注“Coming soon”。这些是作者报告的展示，不是 DexLab 已验证的可运行发布版本。

代码提交、任务资产、策略／控制器可用性、再分发条款、原生 solver 身份和有效参数均未准入。论文许可不等于代码或资产授权；不能从视频推断源码可访问，也不能将不同框架计作独立物理引擎。本补充不改写历史 38 篇调研数量，不声称新增复现。

## 相比现有研究，究竟新增什么？

现有[灵巧操作路线](https://github.com/huangkiki/Dexlab/blob/main/docs/dexterity-roadmap.zh-CN.md)与 [#48](https://github.com/huangkiki/Dexlab/issues/48)已经覆盖手内旋转、接触切换、掉落和独立评分。再加一个旋转演示，会与原范围大量重复。

增量假设应收窄为：**在不重置物体、不恢复预备抓姿的情况下，改变技能间的手物相对运动目标，是否会暴露单技能对照不能解释的可重复失败？** 研究过渡历史、首次接触分歧、支撑保持和误差累积。这是 DexLab 拟研究的问题，不是 UniCross 已经证明的物理精度结论。

借鉴任务／阶段表达，暂缓采用训练体系。场景选型与受控 solver 归因分开；策略成功率较低，本身不能定位几何、驱动、接触模型或求解过程的责任。

## 候选探针，不是已冻结的执行协议

可考虑原创的“保持 → 指定手内旋转或平移 → 再保持”探针。目标在手部坐标系定义，披露腕部约束、初始准备和所有外部支撑，禁止隐藏物体状态注入或技能之间重置。先验证可用控制器，随机动作不能称为复现操作技能。

将连续序列与单独声明的组成技能对照比较。同 seed 不保证初态相同，不能静默恢复中途状态。最小片段必须先重现完整动作前缀的对应现象，才能用于归因。固定命令回放与固定闭环控制器是两种实验：引擎实测状态出现分歧后，同一控制器也可能发出不同命令。

执行前冻结几何／惯量、有效材料／接触设置、时钟、控制、适用配置、工况、参照、阈值和资源预算。独立保留记录完整性、数值一致性、物理参照适用性、任务结果及剩余因果解释。所有失败、成本与缺失观测都保留；开发后须使用真正新的冻结验证条件，历史记录不能冒充未见留出。

遵循已有六引擎适用范围与证据规则，但不因增加一条参考就启动六引擎实现计划。所选探针依赖细特征 SDF 时，才适用 [SDF #178](https://github.com/huangkiki/Dexlab/issues/178)；[布料 #179](https://github.com/huangkiki/Dexlab/issues/179)只适用于布料／柔性扩展，不是刚体旋转的人为前置。真实材料验证仍需对应实测；独立合成参照研究不等待无关硬件数据。

## 复用／暂缓决定

**复用：** 手物相对目标与连续技能过渡问题，接回 #48，而非另起重复任务线。

**暂缓：** 上游复现、策略训练、新仿真框架、大规模资产下载和比较性能主张，直到来源、控制器、许可及运行时证据齐备。本文不授权训练、付费服务、新调度器、引擎修改、阈值修改或原生运行。

只有可用控制器和合格夹具能够检验超出现有 #48 的过渡机制假设时，再推进实现；否则保留为参考。第一项交付是来源／准入核查与增量问题，而不是成功率表。相关分类与执行入口修正已由 [#177 / PR #180](https://github.com/huangkiki/Dexlab/pull/180)交付；执行优先级以[当前工作](https://github.com/huangkiki/Dexlab/blob/main/docs/current-work.zh-CN.md)为准。[PR #176](https://github.com/huangkiki/Dexlab/pull/176)记录本参考资料的文档审查与验证。
