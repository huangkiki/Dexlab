## 首个路径与证明

首个目标为既有有限 Genesis 夹具的夹持—保持—释放入口 `dexlab.genesis_pinch_probe`，独立评分器为 `genesis_pinch_score`。它已有原生实现及历史隔离适配器对照，能直接核验迁移前后。历史候选只证明对应冻结版本；新的公共接口、当前 UniSim 修订及实际生产切换仍需重新检查。新的外部 PD 批次继续使用独立协议，后续消费已准入接口。

通过 Git 修订保留原生源码及冻结协议，供可复现的参考执行。对照通过后，生产入口才切换到 UniSim 并删除原生场景、生命周期及观测代码。参考路径显式选择，不允许静默回退。保留 CLI、控制和输出行为及全部物理失败。共享实验逻辑继续留在 DexLab。

资格前冻结原生/适配器源码树、官方运行时身份、模型、控制器、工况、验收与输出模式。两条路径在 0.5 ms 下比较现有全部16个 `force-limit-v1` 工况；另在三个支持步长下执行默认夹持、张指对照，各带2次重置重放。共38次基础进程启动、56个四秒回合。前三版历史候选使用单执行者，至多48次启动、完整进程墙时累计90分钟、单进程最多15分钟；这份迁移开发预算与新批次6小时/700次预算分开。保留所有尝试，启动前检查剩余额度，覆盖不全仍为未完成。源码/运行时准入与冻结清单形成前，不执行此对照。

保持初态数值一致性阈值1e-12、轨迹状态1e-9、接触力1e-7 N。独立保留原有1e-8 N接触力账、1 mm穿透、5%重力归一化动量残差及保持/释放检查。这些阈值用途不同。要求科学通过/失败结论一致，不要求每例抓取成功。比较完整接触身份、位置、法向、深度、力及时刻；仅在物理身份匹配后允许接触槽置换，拒绝记录缺失或重复。当前仅审查过链接/自由度的批存储表示差异，必须显式报告。

## 冻结对照与恢复

`scripts/run_contact_migration.py` 为这次有界迁移提供 `freeze`、`run`、`status` 和 `check`，复用 `bounded_run.py` 与 `research_guard.py`。使用隔离候选 Python 环境；冻结时复制两端源码、记录基线和逐文件哈希、生成准确的可移植模型、对照已准入官方 wheel 回执核实安装代码，并记录依赖及运行时身份。私有清单中的本地工作树路径是执行输入，不属于公开报告内容。

每次运行指定 38 个冻结启动身份之一。追加式哈希链账本在启动前预留完整 900 秒进程额度。恢复保留全部预留和尝试；进程仍在运行或无法核实终止时，禁止新领取。只有受限执行器的终态回执与已停止服务才能释放预留。基础设施或记录故障经过明确理由说明后最多重试一次，仍共享已冻结额度（历史候选为 48 次启动／5,400 秒）。记录完整的物理结果不得重跑到成功。历史损坏、源码／运行时／模型身份变化或额度耗尽均停止执行，不重建预算。

实现修正后必须冻结新源码版本，不能修改旧记录。`freeze --previous-comparison` 停止旧候选的后续领取，继承全部启动次数及墙时，并绑定前序清单和账本末端哈希。此前物理失败仍属于旧候选的结果。控制器使用 Python `-I` 启动，防止 shell 的外部 Python 路径混入已准入依赖清单。

离线 `check` 核对封存证据、源码与工况身份、每步状态和接触时刻、按几何及位置匹配的完整接触、独立科学评分及精确重置重放。覆盖情况与物理一致性分别报告；最终验收还要求 `--verify-runtime` 再次核实安装代码字节。缺少工况只形成不完整报告。原公开力限额评分器保留采集源码校验；迁移检查器绑定两条明确审查的记录源码后，调用同一独立评分逻辑。

首个候选通过 UniSim lint／类型／打包门禁、1,631 项基础测试（141 项跳过）和 110 项真实 Genesis 1.4.3 测试（16 项跳过），但首次完整 1 ms 对照失败：两条路径的重置重放均精确一致，原生接触力从第二步起出现差异。工厂静默覆盖了调用方无前缀的 `friction_cone` 参数，实际选择了棱锥而非椭圆摩擦锥。修正候选使用 `genesis_friction_cone`，在记录前核对实际枚举名称，并拒绝会被静默覆盖的工厂参数。原生参考现分别保存请求配置与求解器生效配置。轨迹阈值保持不变。[#143](https://github.com/huangkiki/Dexlab/issues/143) 仍要求新冻结对照和生产切换；这两次失败对照启动及全部开发尝试均保留。

第二版冻结候选通过 1 ms 与 0.5 ms 对照，但 0.25 ms 从 0.52475 s 起未通过完整接触点位置匹配；任务评分和精确重置重放仍通过。原生方块与隐式 MJCF 方块惯量相差一个 FP64 量化单位。仅物化模型的诊断另发现，中间编译 XML 写入器将显式惯量截为六位有效数字。修正按原生基本体解析公式的计算顺序显式描述质量与惯量，并在 UniSim 导出时完整保留显式惯性参数。当前原生读回与参考质量／惯量精确一致，但尚未证明轨迹等价。第二版六次启动、第一版失败及累计成本全部保留；第三版须通过原接触／状态／力阈值及完整矩阵，才能切换生产。

## 原生隔离结果与存储对齐协议

[24 进程隔离结果](evidence/unisim-contact-migration/native-isolation-v1-summary.json)仅使用开发工况 `dev-cap-0.2`：1／2 个 Quadrants 线程 × link／DOF 参数批存储开／关 × 原生环境数 0／1／2 × 两次独立进程重复，步长 0.5 ms、时长 4 s。运行前重新核实官方 Genesis 1.4.3／Quadrants 1.3.3 代码身份。32 个记录世界都保留低力无法保持的结果，并通过既有数值／物理有效性检查。工作包消耗 361.494566 s；冻结 16 GiB／4 核配额下，单次进程组峰值 1.457 GiB，无 OOM。

同一存储配置内，线程数、环境数及独立进程重复均未产生观测差异。仅开启 `batch_links_info` 和 `batch_dofs_info`，就复现了此前差异：最大合接触力差 `0.0008664952219903156 N`、角速度差 `0.0003385957228926784 rad/s`，首次接触位置不匹配在 1.63 s。这里隔离的是两个存储选项的组合因素，尚未定位到具体编译运算或分别判断两个选项。8 组改变存储的基准对照未通过原逐点判据；16 组独立进程世界配对与 8 组进程内世界对照均零差异通过。这些重复不增加任务类型。

批存储原生记录与第三版保留的适配器记录也通过了未放宽的迁移判据：命令、位置、速度、合接触力及全部匹配接触完全一致；四元数与角速度差最多为 `1.11e-16` 和 `2.71e-20`。因此，这个开发差异无需经过适配器就能产生；该证据不能推广成任意框架路径等价。

第四版冻结两层验收：保留“历史非批存储原生 → 批存储原生”的数值配置差异；“**存储对齐原生 → 适配器**”继续使用原初态 1e-12／状态 1e-9／力 1e-7 N 阈值、既有物理评分、全部 16 个力工况和重置／步长对照。两端的实际存储标志必须一致。原生参考用显式 `--batched-info` 选择新配置，省略时保留历史配置；#145 与该固定模型对照独立验收。
