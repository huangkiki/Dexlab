# 刚度减小重叠，但末态误差不随步长单调改善

[English](impact-stiffness-results.md) | [简体中文](impact-stiffness-results.zh-CN.md)

**27 个有效工况中，24 个通过原有末态判据，只有 2 个同时满足独立的 1 mm 重叠预算。** 本次使用官方 MuJoCo 3.15.0，复用九个已发布等质量工况，仅新增十八个较高刚度工况，没有重复运行历史仿真。1 mm 是球直径 1% 的工程几何预算，不是材料实测参数或完整抓取验收。

![刚度与步长敏感性](evidence/impact-stiffness/sensitivity.png)

k=100000 s⁻² 的九例末态均通过，但采样重叠仍达 1.58–6.40 mm。k=1000000 s⁻² 时重叠进一步减小，然而 0.5 ms 步长下三种速度的相对动能误差均为 2.246%；1 ms 的末态几乎精确，0.25 ms 的动能误差则为 0.7901%。三个采样点不支持单调收敛结论，不能依据偶然准确的末态推荐较粗步长；本轮尚未测试接触相位敏感性。

联合通过的是 stiffness-10/12（0.5 m/s，1/0.25 ms）。**stiffness-13 仅在浮点边界上被拒绝**：存储重叠为 0.0010000000000000009 m，比预算高约 8.67e-19 m，不构成有物理意义的超量。保留冻结的严格比较，正式计数仍为两例；不能用表格四舍五入后的值重新统计。

## 方法、证据与复现

[预注册协议](impact-stiffness-protocol.zh-CN.md)与[清单](evidence/impact-stiffness/manifest.json)冻结于提交 `73f3113f21539ff641c1aed34f17680fdc604cea`：两个 1 kg、半径 0.05 m 的球体，入射速度 0.5/1/2 m/s，步长 1/0.5/0.25 ms，总时长 0.2 s。Euler、Newton（100 次迭代、容差 1e-12）、直接 solref=(-k,0)、常数阻抗 0.9；无重力、摩擦、自旋或驱动。先验弹性参考为等质量速度交换及动量、动能守恒，没有拟合恢复系数。

[机器可读结果](evidence/impact-stiffness/results.json)包含原生峰值力、有符号冲量向量和冲量误差范数、采样接触时长、各阶段耗时、XML/轨迹哈希、运行时身份及全部判定。协议中的“有符号冲量误差”通过有符号向量及明确解析参考表达；标量误差字段是非负范数。峰值力与接触时长依赖采样步长，不是连续时间极值或已独立验证的瞬态力真值。

从 [v0.44.0](https://github.com/huangkiki/Dexlab/releases/tag/v0.44.0) 获取 elastic-impact-raw-v1.zip，从 [v0.44.1](https://github.com/huangkiki/Dexlab/releases/tag/v0.44.1) 获取本次原始归档。核对[归档哈希](evidence/impact-stiffness/archive.json)，分别解压后离线评分：

```bash
python -m dexlab.impact_stiffness --baseline baseline --input new --output rescored.json
python scripts/plot_impact_stiffness.py --help
```

输入目录应包含 manifest.json 和工况子目录。科学字段应复现一致；评分墙钟时间属于观测值，会变化。合并前核验基线运行时与文件哈希绑定。

## 成本、边界与下一步

十八个新增工况的原生批次耗时 0.05229 s；累计建模、推进、观测、工况总耗时分别为 0.01013、0.01041、0.01436、0.04903 s。独立联合评分 0.04343 s。受限服务墙钟分别为仿真 0.886 s、评分 0.384 s，不含安装与发布验收。硬件为 Intel Core i9-14900K，CPU FP64；强制 16 GiB、两核、128 进程、零 swap、1800 s 时限与独占研究窗口。复用基线来自同硬件的前一批次。这些极短且未重复的测时只能说明成本，不能作为速度排名。

对抓取研究的启示是：末态速度吻合还不足以验收接触，必须单列几何预算，并检查较高数值刚度对应的步长敏感性。本轮不证明真实材料接触准确、抓取力已校准、其他引擎更差或某一步长普遍最优。u/sqrt(k) 只是标量模型诊断尺度，完整瞬态模型尚未独立验证。下一步预注册接触相位偏移与瞬态诊断，区分末态巧合和稳健表现，再将合格的接触测试关联到承载与滑移。
