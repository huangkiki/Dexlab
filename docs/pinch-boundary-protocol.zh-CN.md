## 夹具与来源

[v1 JSON][protocol]保存唯一的数值定义，并绑定原 Genesis 夹具／评分源码的提交与哈希。几何、质量、轴向、初态及轨迹来自 `genesis_pinch_probe.py`；共同碰撞对、外部 PD、扩展矩阵、记录接口和独立几何评分是新要求，历史运行不能替代其资格验证。

世界坐标右手系，长度／质量／时间／力单位为 m/kg/s/N，z 向上。四元数顺序 `wxyz`，所有初始姿态为单位旋转、初速度为零；重力 `(0,0,-9.81) m/s²`。

| 物体 | 形状、质量与质心坐标系对角惯量 | 初始位置／自由度 |
|---|---|---|
| 桌面 | z=0 固定水平平面 | 无运动自由度 |
| 方块 | 边长 40 mm，质量 0.064 kg；三个惯量均为 `m*s²/6 = 1.706666666666667e-5 kg·m²` | `(工况偏移,0,0.02)`，六个自由度 |
| 升降架 | 无碰撞几何，1 kg，惯量 `(0.01,0.01,0.01) kg·m²` | `(0,0,0)`；+z 移动关节，范围 `[0,0.15] m` |
| 左／右夹指 | 半尺寸 `(0.01,0.03,0.02) m` 的方盒，各 0.1 kg；惯量 `(4.333333333333334e-5,1.6666666666666667e-5,3.3333333333333335e-5) kg·m²` | 相对升降架的中心为 `(-0.04,0,0.025)`／`(0.04,0,0.025)`；沿 +x／−x 向内移动，各 `[0,0.03] m` |

广义坐标固定为 **lift、left_slide、right_slide**，初值均为零。夹指中心为 `(-.04+q_left,0,.025+q_lift)` 和 `(.04-q_right,0,.025+q_lift)`。没有夹指转动自由度、物体附着或运行中状态校正。B 核验原生位姿／轴向与此运动学一致；C 可据已核验关节坐标重建夹指 OBB。

恰好启用六对几何：方块／桌面、方块／左指、方块／右指、左指／桌面、右指／桌面、左指／右指。显式核验自碰撞和过滤设置，名称相同不能证明碰撞对一致；固定基座和升降架没有碰撞体。四个碰撞体名义摩擦均为 0.5，名义零摩擦对照全部请求 0。B 保存真实下限、组合规则、滚动／扭转项及原生接触／求解配置，并在批次内保持各后端配置固定；同名义 μ 不等于材料等价。

读回几何、质量惯量、轴、限位、初态、碰撞对，以及已关闭的阻尼／附加惯量／隐藏驱动。数值导入核验采用绝对容差 `1e-10 m`、`1e-12 kg`、`1e-14 kg·m²`，另加相对 `1e-9`；离散身份、轴向选择与碰撞过滤必须匹配。这是预登记的导入容差，不是实测物理精度。

## 整数时钟与外部控制

每条记录对应一个 1,000／500／250 µs 物理步，原生内部物理子步数为一；求解迭代不算额外物理步。控制周期始终为 1,000 µs。零起始步号 `i` 满足 `t_before=i*h`、`t_after=(i+1)*h`、`tick=t_before//1000`；仅在 `t_before%1000==0` 时用**步前状态**更新控制。两次控制更新间保持目标、限幅前命令与限幅后命令，不按物理频率重算 PD。四秒共 4,000 次控制更新，物理记录为 4,000／8,000／16,000 条。

在控制时刻 `t`（秒）：

```text
closure(t) = 0.012 * min(t/0.5, 1)，当 t < 3.2；此后为 0
lift(t) = 0.08 * clamp(t - 1, 0, 1)
q_ref = [lift, closure, closure]
u_raw = [1000,500,500] * (q_ref - q) - [50,20,20] * qdot
u = clip(u_raw, -[50,cap,cap], +[50,cap,cap])
```

张指对照全程 closure=0，仍执行升降轨迹，逐指限额 10 N。两指正广义力均向内，右指的世界力方向为 −x。MuJoCo 使用单位传动比力执行器，Genesis 使用直接广义力。关闭隐藏位置驱动、被动关节阻尼和附加关节惯量，并核验有效值。不加目标速度前馈或重力补偿。两引擎分别使用自己的闭环状态，不要求输出相同的力序列。

已知力夹具保留升降架／夹指质量与轴，将初始关节移到 `q=(.075,.015,.015) m`，关闭重力和全部碰撞对，从静止开始。三个常量广义质量为 `(1.2,.1,.1) kg`。依次执行四个 10 ms 阶段：`[0,0,0]`、`[2,1,-1]`、`[-2,-1,1]`、`[0,0,0] N`。确认原生驱动、阻尼与附加惯量关闭，全程远离限位，三广义坐标不受限位／接触力。方块观测仍保存，但不加入这三个自由度的解析检查。任何模式切换准备均在声明的零速初态快照前结束，测量期间不写状态。

**三项力检查分开：**

1. 直接力输出：逐分量 `abs(native_u - command) <= 1e-9 N + 1e-9*abs(command)`。使用通过资格核验的原生实际施力接口，不复制命令，也不用加速度反推力冒充原生输出。
2. 无接触动力学：逐步检查已知命令 `F` 和质量 `M`，`||M*(v_after-v_before)-F*h||₂ <= 1e-10 N·s + 1e-6*||F*h||₂`。从声明初态独立积分分段常力的解析位置；任意时刻的位置误差界为 `0.5 * sum_j(||M^-1 F_j||₂ * h_j²) + 1e-8 m`。此预先固定的一阶积分包络覆盖显式／半隐式 Euler 的位置偏差，不拟合运行结果。
3. 方块接触力账：逐接触力总和与原生物体净接触力的世界坐标最大分量误差 ≤ **1e-8 N**。动量标准另列。这三种容差不能互相代用。

B 准入前保存官方稳定兼容引擎／核心／绑定／编译器身份、源码和原生库哈希、精度／设备、积分器、求解算法、迭代／容差预算、接触律及有效参数读回。区分输入、原生读回、固定源码推导和不可观测字段。框架版本、调用者选项或迭代上限不能证明核心版本、解析后参数或实际迭代次数。必要状态／执行器／接触观测缺失会阻止准入；可选原生遥测保持 null 并附原因，不猜默认值。

## 独立评分

窗口使用**步后样本，包含两端点**。保持 `[2,3] s`：每个样本方块质心 z ≥0.06 m、两指均有效、非夹指接触竖直分量绝对值之和 ≤0.01 N。有效夹指定义为其**任一**原生逐接触力模长严格大于 `1e-8 N`，保留旧定义，但不将它等同于法向载荷或摩擦能力；实际法向载荷另按原生法向投影报告。释放 `[3.8,4] s`：质心 z ≤0.03 m，夹指逐接触力模长之和 ≤0.01 N，不能用可能互相抵消的合力模长代替。

张指对照全程质心 ≤0.03 m，保持窗口不得有有效夹指接触。名义零摩擦对照保留普通保持／释放评分和负对照解释；异常保持需检查几何支撑和实际摩擦，不调阈值或隐藏结果。接触存在阈值和力账容差虽然数值都是 `1e-8 N`，含义独立。

方块动量逐完整步检查 `||m*(v_after-v_before) - (sum_contact_force + m*g)*h||₂ / (m*9.81*h) <= .05`，包括第一步；正式／对照中没有直接作用于方块的外加力。记录完整性、数值状态、穿透、保持和释放分别报告；证据有效的抓取失败仍是实验结果。

共同几何对所有碰撞对使用同一 `state_after`。方块／桌面和夹指／桌面使用解析有向方盒支撑距离：`max(0, sum_i(half_i*abs(axis_i.z)) - center.z)`。有限 OBB 之间检查六个面法向和九个边叉积方向，仅跳过**长度严格为零**的平行叉积，其余均单位化。对单位轴 `n`，`s(n)=r_A(n)+r_B(n)-abs((c_B-c_A)·n)`，`r(n)=sum_i(half_i*abs(axis_i·n))`。存在 `s<=0` 时穿透为零，否则取全部轴的 `min s`。这定义固定姿态下最小平移分离深度，不能使用包含关系下错误的投影区间交集长度。轴集合依据 [Eberly 的 OBB 推导](https://www.geometrictools.com/Documentation/DynamicCollisionDetection.pdf)第 2.1–2.2 节。有效四元数在几何计算时归一化，原始状态不改写；非有限或无效几何不得按无碰撞处理。

六个启用对均检查共同深度 **1 mm** 预算，保留碰撞对和首次超限样本。可观测的原生深度单列采样时刻与 1 mm 检查；不可观测就明确缺失，既不填零也不计为原生通过，不能替代必需的共同几何。C 必测旋转边缘、近平行／严格平行、完全包含、分离、恰好接触及禁用碰撞对。该指标是离散步几何，不是连续碰撞检测或材料变形量。

曲线保留三次重复、首个记录阈值违规、相对夹具位移／速度、实测法向载荷、接触冲量和成本。首次阈值违规不等于真实滑移起点。仅在测量支持单调性时报告测试网格过渡区间；反转或重复分歧报告通过区段与混合结果。

## 可恢复预算与完成条件

B 先分配一个不可变批次 UUID 和持久预算账本。任何资格尝试之前，冻结**资格清单**，绑定该 UUID、协议／工况／模型／采集代码／资格检查器／环境哈希与候选原生配置，不依赖未来资格结果。A 的工况展开输出不能充当资格清单。

资格完成并通过 C 的独立验收后，冻结**正式清单**：引用精确资格清单哈希，保留同一批次 UUID 和同一账本，绑定全部资格尝试、已消耗额度、准入证据与最终评分器。只向已有账本追加正式清单哈希的授权，不重建或清零账本。协议、工况、模型、环境与采集行为保持已核验版本；改变版本需要重新审查资格与预算安排，不能自动换批次续额度。每次尝试保存阶段及精确清单哈希；未知哈希、断裂的清单链、改变的批次身份或缺失旧消耗均阻止执行。B/C 必须测试此阶段切换的恢复，包括正式清单授权前后中断。

单执行者账本是持久化的批次依据，绑定批次 UUID、初始资格清单哈希及获授权的正式清单扩展。资格与正式尝试共享累计额度。在现有独占研究锁内，启动前原子预留尝试 UUID／工况 ID、一次启动和 `min(1800 s, 剩余墙时)` 以内的超时额度；先持久化 `reserved`，再启动并记录 `running`、可核实的进程／服务身份、boot ID、起始时钟和截止时间。即使启动失败，预留也保守计作一次启动；恢复时不能删除或清零。

外部监督者到截止时主动终止整个进程组／服务，计入启动至退出的全部墙时。恢复时先检查已有活跃句柄，观测超时不代表进程结束，也不能重复领取。终止尝试按监督证据结账；无法恢复墙时则保留全部预留额度作为消耗，记基础设施失败。进程、机器或协调者重启不能增加预算。尝试事件只追加，原子账本快照只能从全部事件重建，不能只统计成功运行。

总限额为 21,600 进程秒和 700 次启动，包含资格／桥接／正式／对照／重试。最多 650 个基础身份留下最多 50 个额外启动。每工况最多重试一次，且只允许基础设施或记录错误，仍受总额限制；物理失败不重试。允许重试后取得有效记录，也必须保留旧失败。开发／提交回归单独记账，但不能把实验尝试改称调试来规避额度。

正式启动前，用每个后端／步长的完整四秒资格进程成本评估余下批次，至少采用同类已测最大成本乘以剩余工况数，归档依据及剩余额度。预测超预算时阻止正式启动，在 [D][d]／[Discussion][discussion]记录恢复决策，不能保证完成或静默缩减矩阵。预测仅评估可行性，不是保证。已准入批次运行中耗尽预算时，保留全部尝试，余项标为未运行并写恢复条件。

完整交付要求 **594 个正式项和 24 个对照**全部取得有效实验终态，所有尝试保留、独立复算完成、全部图表数字可追溯冻结记录。`completed` 可以含保持／释放／穿透失败；`numerical_abort` 仅在前缀和首错证据满足要求时计为结果。未运行、不可恢复损坏或基础设施重试耗尽只能阶段交付。桥接、冒烟、完整的启动失败列表或一份报告文件都不能代替正式批次。C 冻结前须实际测试恢复不重复领取、预算不清零、错误哈希拒绝复用、失败不覆盖与图表重建。
