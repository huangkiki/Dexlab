## 固定源码与文档措辞差异

| 项目 | 本课采用的证据与处理 |
|---|---|
| noise、cutoff | noise只是元数据；一般cutoff是幅值限制而非低通频率；碰撞sensor另有查询语义，contact忽略 |
| history | 内置sensor读与advanceStart写分开；超出最老边界钳为最老值，并非无限回放；USER/PLUGIN未走同一读取分支 |
| contact found | 匹配循环直接遍历d.contact，不筛正力/efc_address；无力记录也可能found>0。netforce无匹配仍写固定normal/tangent，必须据found判空 |
| tactile | 实际3N通道优先；正穿透max、切向abs投影累加；支持分派中的六类primitive/SDF/带octree mesh，hfield不在支持分支；不照抄XML页“仅SDF”的旧限制 |
| 相机路径 | camprojection忽略principal/orthographic，camera ray显式intrinsic主点中心偏移与正交横向范围有版本差异；不承诺与渲染像素一致 |
| classic Renderer | 旧renderer.py是转发文件；实际代码在rendering/classic，shape采用(H,W)，不照抄docstring局部(width,height)文字 |
| depth、segmentation | depth为轴向长度，背景far；segmentation为(objid,objtype)与(-1,-1)背景，不是body/class label，out也非统一复用规则 |
| passive viewer | 默认可视化副本复制与state_only的INTEGRATION+forward分支分开；sync可回传GUI输入，不能视为无副作用显示 |
| Filament | 独立Context/scene/target/view、CPUbuffer读回，render等待且返回None；不以同名Renderer套用classic契约 |

逐项固定行锚分别位于三篇正文，不用一个宽泛文档URL替代实现依据。低层distance函数、classic投影视口计算也沿调用链核对，避免只读sensor上层就推断所有geom/相机行为。
