## 实际静态检查

```sh
git diff --check
git diff --cached --check
python scripts/check_docs.py
python scripts/check_examples.py
```

文档/语法检查在Python3.10.12与CI对应的Python3.12.12通过：全仓相对Markdown链接、**7个Python文件、7个文档Python片段、6个XML文件**。XML只使用ElementTree解析，未进行MJCF schema或物理语义验收。全仓Markdown无TAB及其他非换行控制字符；E6的显示公式独立双美元分隔行、代码围栏、章节编号和40道练习逐项检查通过。

[source manifest](../sources.json)从62扩至**86个MuJoCo官方文件**，新增24个实际引用文件；全仓**611个MuJoCo blob链接**固定同一SHA、路径均入manifest，行锚有序且在实际文件范围内。另有[external manifest](../external-sources.json)的**6个JAX文件、16个固定blob链接**，本轮新增control_flow/loops.py。所有文件按Git blob算法计算身份，与固定官方tree/manifest核对一致；不把vendored Warp换成未读的外部最新版，也不把JAX归入MuJoCo的提交身份。身份/行号验证不替代逐段语义阅读。

第一轮来源检查发现`plugin/elasticity/register.cc`与`cable.cc`的结束行各超出文件一行，已将23/319分别修正为实际22/318并重跑全部检查。早期第五篇生成时漏了docs目录前缀，已移动到与导航一致的目录；标题跳号及XML属性表初始锚点过于宽泛也在主审预读后修正。固定源码下载曾出现SSL连接中断，限定重试后重新核对Git blob身份，没有采用不明缓存或跳过验证。

**未做**：原生MuJoCo/JAX/Warp import、动态库加载、模型编译、forward/step、回调执行、形变/接触/IPC求解、JIT、图捕获、渲染、CPU/GPU传输、导数计算、训练、benchmark或任何实验。片段若以后执行将有其README声明的原生行为，本轮只解析文本。

## 审查中特别保留的结论

| 发现 | 课程处理 |
|---|---|
| 全局callback与每Data插件状态不同 | shared model/Data隔离不自动隔离闭包；Python getter也不承诺保存外部裸C指针 |
| 注册与生命周期 | header契约与实际空指针保护分别说明；旧文档resource.getdir及Solid/Membrane不能当当前可调用接口 |
| 材料与XML | elastic3d是mjSpec-only；插值壳bending有真实编译/计算分支，旧否定句不沿用 |
| IPC的名称与算法 | 实际是无log barrier的AL+CCD；一般附着、摩擦与初始非正gap边界逐项解释 |
| partial advance | 运动部分接受仍time+=h；mju_warning为日志，不由rollout的Data warning检测完整覆盖 |
| 回调重复评估 | 有2D flex时sensorAcc可先free-flight再IPC重算；回调次数不能当物理步数 |
| FD矩阵 | nx=2nv+na；nu是原始ctrl标量宽度、nactuator是数量；不自动给出SO3三维控制切空间Jacobian或plugin_state列 |
| JAX反向边界 | 公开step→forward→solver无自定义导数包装；进入约束solver且iterations≠1时外层while限制普通reverse-mode，结论不外推全部模型/后端 |
| Warp历史缓冲 | vendored后端有delay/interval；MJX make_data_warp跳过history复制，与直接vendored初始化不同，标为源码差异而非已复现故障 |
| fluid模型 | ρ和η可单独起效，frame/全长半长分别核对；常规added-mass调用传NULL加速度，不宣称完整附加惯量已进入M |
