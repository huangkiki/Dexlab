## 关键源码结论与适用边界

| 项目 | 实际处理 |
|---|---|
| rollout ctrl=None | 默认CTRL mask下不会清旧ctrl；示例显式给control数组。排除CTRL的全零也不等于SO3中性 |
| warmstart与FULLPHYSICS | C++写qacc_warmstart，不沿用Python注释的qfrc称呼；FULLPHYSICS含history，但不覆盖全部输入/隐藏/外部状态 |
| 模型兼容性 | Python只比较state/control宽度、nv、nsensordata；C++取首model的nbody/neq，不能只靠这些检查混任意模型 |
| warning与采样 | warning后复制剩余帧；最后一步故障不一定有平台段。积分后state与step留下的sensor不自动同阶段 |
| MJX身份 | 包3.15、树内vendored元数据3.14、Warp extra1.17分别记录；CPP I/O不当完整step后端 |
| JAX支持边界 | 实际积分器分派不含DISCRETE；history存储不等于CPU的delay/interval实现；dtype不由CPU构建自动继承 |
| Data.where | 裸(B,) mask没有按每叶rank自动reshape；示例JAX路径在vmap内用scalar，Warp共享池单独解释 |
| 随机化 | 逻辑env/episode/stream与worker调度脱钩；质量/惯量/派生常量/BVH不能独立任意改 |
| 恢复 | mask、同进程copyData、模型文件、图像回放与外部RNG/controller各有范围，不宣称可移植全量快照 |

四篇正文提供公式假设、量纲、字段、固定实现行锚和带答案练习。JAX用于讲清原生MJX依赖的语言/执行边界；没有将课程选择的JAX版本称作与MuJoCo3.15已验证兼容。
