对 [sources.json](../sources.json) 中 **31 个官方文件**，计算 `SHA1("blob <byte-count>\0" + bytes)` 并对照固定官方 Git 树；全部一致。全仓本引擎 GitHub blob 链接均核对固定 SHA、manifest 收录和存在的行锚；重要声明逐段人工对照实现。文件身份与行号存在只说明引用身份，不能代替相关算法的人工阅读，也不等于审计了整个上游仓库。

本阶段新增引用的官方源文件是 `engine_init.c`、`engine_passive.c`、`engine_sensor.c`、`engine_derivative.c`、`engine_derivative_fd.c`、`engine_island.c`；完整固定链接见[source map](../source-map.md)。公式分开标明连续加速度、冻结接触集合、有效 metric、稳定符号线性化、无 adhesion 与后处理等前提。
