源码与公式由作者自审；独立主审/发布由后续流程完成，本记录不将预读或自审写成最终批准。特别核对：

- env_id 是应用 filter data 约定；共享静态 world 是有意的例外，aggregate/空间平移不构成完整隔离。query 与 simulation filter 仍独立。
- task.run 不得阻塞，零 worker dispatcher 会同步 run/release；checkResults/completion task 不替代 fetch。每个在途 scene 的 scratch 不能被另一 scene 同时覆盖。
- Direct GPU 需要首个真实物理步初始化，并会改变常规 CPU readback/sleeping 契约；GPU broad phase 与 dynamics 是不同设置。
- articulation 请求子集仍以全 Scene maxDofs/maxLinks 分块；GPU index 与请求 row 分开。JOINT_FORCE/target 的 get 读回输入值，不是求解器测量。
- CUDA context 锁、scene 锁、start/finish event 和 D→H readback 是不同边界；bool 可能不含异步错误，借用 contact 内部指针会在下一 simulate 失效。
- zeroCache/eALL 不等于完整 reset；Direct GPU UPDATE_KINEMATIC 会清掉相关加速度/传力输出。控制输入、引擎状态与应用历史均需明确重置策略。
- mass=0 的原生特殊语义、setMass 不更新惯量，以及 enhanced determinism 不支持 GPU 的范围已保留。
- Binary reader 验证 header/GUID/platform，并在提供内存内构造对象；collection.release 只销毁容器，backing memory 需晚于对象释放。XML serialization 在固定头文件已 deprecated。
- RL bootstrap 式明确持续任务/外部时间截断假设；并未声称 PhysX 实现奖励、终止、优化器或迁移学习。
