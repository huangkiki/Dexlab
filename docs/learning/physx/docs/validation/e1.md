## 实际检查

检查环境：Linux，Python 3.12.12，g++ 11.4.0。没有安装或构建 PhysX 二进制；C++ 检查使用固定源树的公开头文件。其递归依赖共 102 个头文件，下载内容均通过对应 Git blob 校验；SDK 源码内引用但未公开的 Switch 平台头文件未下载，Linux 预处理路径未使用它们。

在仓库根目录执行（`PHYSX_SOURCE` 指向含 `physx/include` 的匹配官方源树或已核验缓存）：

```bash
git diff --check
python scripts/check_docs.py
python scripts/check_source_links.py --source-root "$PHYSX_SOURCE"
g++ -std=c++17 -DNDEBUG -fsyntax-only -Wall -Wextra \
  -I "$PHYSX_SOURCE/physx/include" examples/e1_state_boundary.cpp
```

结果：空白检查、相对 Markdown 文件链接、39 个固定源码 blob 与固定源码链接/行范围通过；C++ 语法和类型检查退出码 0，无诊断。新脚本 `scripts/check_source_links.py` 也通过 Python AST 语法检查。另用 Git tree 对照确认 manifest 不是仅与本地文件自洽。

`check_docs.py` 不验证远端 URL、Markdown 锚点或语义。`check_source_links.py` 只读本地匹配源码，不自动联网，固定源码不存在或内容不符会失败。公开来源本轮已从固定提交取得并校验；链接未以 HTTP 页面渲染或浏览器视觉效果验收。
