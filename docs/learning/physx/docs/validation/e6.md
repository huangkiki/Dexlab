作者自审与主审预读用于发现问题，不等于已批准发布。提交前已逐项核对以下易误读处：

- custom geometry 仅借用 callback 指针；`isValid()` 不验证几何算法。cylinder 无 margin 的质量与 margin 非零分支区别明确。
- `Px1DConstraint` 的 J 内置 body 1 负号，COM-local/world frames 与 force report 参考点分开；示例只约束固定 world 轴上的一个标量关系。
- `eHAS_DRIVE_LIMIT` 短注释的 unless 与实际 helper 条件相反：只有它和 `driveLimitsAreForces` 均真才乘 simDt。以实现为准，保留公开 flag 的 deprecated 身份。
- PGS spring 先得 xb，最终 constant 还包含初始速度 bias；迭代使用速度增量，公式已把二者还原为当前总行速度，避免重复计入初速。
- `appliedForce` 是累计冲量；writeback 只收集 eOUTPUT_FORCE 行，再平移角冲量参考点；getForce 用 Scene oneOverDt 转换，不能称完整 actor wrench。
- GPU 的 PCM/contact-modification/pair 表决定是否回退；Direct GPU 对不兼容 constraint 的拒绝及内部 eGPU_COMPATIBLE 禁止设置都保留。
- 本版本有公开 GPU PGS/TGS、articulation、FEM/PBD CUDA 源码；外部 driver/toolchain、实际加载 binary 与宿主运行没有被验证。
- FEM co-rotational 的无阻尼式明确未触发 abs(denom)<1e-15 保护，乘子与刚体冲量量纲不同；Poisson 端点、TGS/non-TGS multiplier 分支分别说明。
- particle `mDensity` 的所引写者存缩放后的约束量；phase 不等于 rigid env_id；deprecated particle-cloth/rigids 等不混同原生 FEM 或普通粒子–刚体接触。
- deformable/particle device buffer 的 lifetime、dirty 和同步不同；post-solve startEvent 不自动等于 CPU 快照或引擎等待用户任意额外 stream。
