源码、公式和片段由作者自审，没有宣称独立 reviewer 批准。重点交叉核对：

- Shape 的 query filter 与 simulation filter 独立；硬编码 mask 在用户 prefilter 之前。缓存 shape 跳过滤并按 BLOCK 处理，不能沿用旧缓存代替新可见性策略。
- Query ANY 与 geometry ANY 的层次不同；固定 touch buffer 可丢弃任意 hits 且无自动溢出 warning，容量相等不等于结果完整。
- query 的 const 入口仍可能 flush/commit；manual update/fetch、应用读写锁与物理 fetchResults 完成是不同契约。
- incoming joint force 使用 child joint frame、low-level link index，root 按定义为零；它与控制输入 cache.jointForce、单个 contact normal 不同。
- RigidDynamic acceleration 的 scene creation flag、Direct GPU 普通 getter 的零返回、首次/reset 和 CPU 速度差分路径均明确，不把无效值写成实测零。
- debug buffer 在 step 入口重建对象图元，接触图元在 finalization 生成后 fetch 合并；安全读取不保证统一采样时刻。deprecated CONTACT_FORCE 实为 CONTACT_IMPULSE，图示没有自动除 dt。
- OmniPVD start/stop 的快照、writer session 与 transport 文件边界分开；再次 start 不是 resume，stop 不替应用 flush/close。
- 关节 wrench 换参考点、刚性安装理想 IMU、针孔 range→depth 公式均注明 frame/单位/假设；这些推导不是运行传感器的证据。
