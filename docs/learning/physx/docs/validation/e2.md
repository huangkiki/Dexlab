原生 API 和量纲结论由作者结合固定声明与实现自审；没有宣称独立 reviewer 批准。特别核对了：

- `PxForceMode` 与 cache flag 不是同一概念，普通刚体力清理语义与持续 `cache.jointForce` 不同。
- Force/acceleration drive 的参数单位、implicit drive 分母及 PGS/TGS 参数分支；一维推导明确是说明性假设，未冒充完整 SDK 数值算法。

- Jacobian 的 COM/world/linear-first 行语义、固定基座省略 root 行、工具点迁移公式；没有虚构通用 IK API。
- `computeJointForce` 不自动含重力、Coriolis、drive/阻尼；回调不是任意控制写入窗口。
