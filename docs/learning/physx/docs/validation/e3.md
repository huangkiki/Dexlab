源码解释和公式由作者自审，没有宣称独立 reviewer 批准。特别交叉核对：

- 本版仅保留 patch friction；PGS 按轴、TGS 成对切向钳制。几何/PCM、strong friction 与本次累计冲量不是同一种缓存。
- PGS 有约束路径至少一遍 velocity/writeback；TGS 用 position iteration 决定内部步长，velocity 阶段不再积分位姿。没有把迭代预算改写成残差容差。
- 刚柔混合 damping 的实现取 MAX，与头文件概述的“柔顺侧”存在输入边界差异；此为源码观察，没有运行复现结论。
- `extractContacts` 只生成法向冲量；friction anchor 有独立位置/冲量。CCD friction stream 缺失，纯 torsional row 没进入 anchor 点冲量；C++ 保留可用性，不把缺项标实测零。
- Articulation 不能按独立刚体处理；也不能把理论交叉响应或存在的 scalar helper 当成当前 SIMD contact 路径。CFM 入口、尺度/响应缩放和实际分母已区分。
- 单行冲量、隐式弹簧、恒加速度子步推导均标假设/单位；不冒充完整 CPU/GPU/宿主算法。
