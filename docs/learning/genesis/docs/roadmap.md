一个阶段对应一个可恢复的 GitHub Issue；总看板统一管理六仓，仓库保留本引擎的原生设计。先查同题 Issue/PR 和实际合入状态，再继续工作。

E0 交付的是导读与导航，不是所有专题。E1–E6 逐个展开目录中的知识点，E7 按完整课程契约审校。依赖必须以实际文档或合入提交核实，不能仅凭 Issue 关闭。

每个 Issue 记录目标、范围、先修、固定版本/来源、交付文件、易错点、验收命令和剩余问题。本轮验收为文档链接、源码/公式核对及最小片段的语法检查；明确区分未运行、源码核对和运行验收。无新实验、训练、性能基准、跨引擎框架或评分器。

有可执行任务时按依赖推进；阻塞时记录原因和恢复条件。没有用户要求不创建定时任务。研究数据与实验最终引用 DexLab。

E1 完成后复盘：已建立后续控制和接触课需要的坐标、惯量、q/v、时间及状态恢复语义；下一项优先 E2，按原生 joint 索引与输入/状态边界展开控制、FK/IK 和任务接口。E3/E4 可在 E1 合入后独立推进。E1 发现的多物理按环境 reset 与 checkpoint 边界保留在专题中，E5/E6 必须继续引用，不能被总括性能力声明覆盖。

E2 完成后复盘：原生输入、限额、实际动力学量和任务成功已分清；下一项优先 E3，接上 qf_applied/smooth/constraint 的来源、采样时点、接触与求解语义。E2 发现的 free旋转控制getter差异、SPHERICAL运动学分支缺口与规划碰撞排除规则，后续不得用笼统支持表覆盖。E4仍可独立开展传感/渲染，E5需等E4实际交付。

E3 完成后复盘：刚体接触从材料组合到约束行、Newton/CG、积分与读数的链路已交付；contact_resolution与solver/integrator分开记录，不用当前默认值填DexLab #125历史。下一项建议E4，把采样frame/时点接到传感与渲染；E5仍依赖E4，E6沿本章标出的SAP/IPC及多物理/可微内部缺项展开。固定版本中已确认的getter/注释差异在E7统一审校，不能抹去。

E4 完成后复盘：观测产生者、坐标/单位/shape、普通sensor采样与RGB lazy cache、投影深度/range和触觉模型已分清。下一项建议 **E5**，E2/E4知识前置已具备，须主审发布后再领取；保留history绕过delay、RGB通用GT/批读接线、segmentation内部ID和min_range未消费等固定版本边界。E6继续热/触觉专项推导与可微内部，E7升级时逐条复核实现而非沿用docstring。
