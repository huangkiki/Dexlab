# 参与 Sim Learning

先选择问题所属位置：引擎 API、源码或示例在该引擎仓库提交；课程导航、共同术语、入口链接和路线衔接在本仓提交。六仓使用同一个 [Project](https://github.com/users/huangkiki/projects/2)，任务只保留在其归属仓库。

一份可验收的引擎章节需要：先修与学习目标、具体概念、原生字段/API、固定源码、公式的假设与量纲、易错点、阅读练习和答案，以及当前的验证范围。对于源码与注释不一致的地方，追踪实际实现和调用点，并把差异写清。

源码查证、代码语法检查、模型加载、实际步进和物理实验是不同证据。当前优先交付引擎知识；最小示例服务解释，未运行必须明示，实验以后复用 DexLab。未完成章节保留计划状态。

本仓的提交前检查：

```bash
git diff --check
python scripts/check_docs.py
```

另需人工核对六仓入口、章节实际发布状态、中英文入口一致性、来源和图形显示。更改 SVG 时检查画布边界、文字是否重叠及缩小显示效果。不得用本地未发布章节更新首页的“已发布范围”。

新增素材说明作者、许可和修改；不提交环境、缓存、凭据、机器地址或实验大文件。欢迎修正解释和补充来源，优先保持原生 API 和简单直接的章节结构。
