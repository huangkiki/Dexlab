## 采集与保存

v2 执行器在 `recording: true` 时接受 `substep_recording: true`。
省略该字段时保留控制步采集，并明确子步资格尚未完成。
现有受控执行器负责资源准入、超时与累计预算；这个开关不提供授权或资源准入。

`libero_physics.record_substeps` 只观察已有的 `sim.step` 调用，每次调用原方法一次，
无论成功失败都恢复钩子。适用范围固定为 MuJoCo 2.3.7、Euler、无插件，且包装器只调用
一次 `mj_step`，不在返回前额外 forward。其他积分器需要独立核验时间语义，当前拒绝执行。

记录保留积分前后的时间、广义位置、速度、激活状态和警告，以及实际驱动力、传动矩阵、
广义平滑力／约束力、压缩惯量、刚体变换、外加力矩、全部约束身份和无损 CSR 雅可比。
每个接触保留几何对、坐标框架、位置、距离、参数、约束地址与原生局部力／力矩。
外加刚体力使用的雅可比明确标为从求解阶段缓存得到的只读计算结果。

每个动作保存一个不使用 pickle 的 NPZ 分块，包括失败动作已经观测到的前缀。
数组形状、类型、空数组和非有限数值证据均保留。`substeps.json` 索引全部分块，
`run.json` 绑定所有嵌套文件哈希。动作／子步编号必须连续，完整动作不能缺失子步观测，
失败回执继续保留。内存中只保留当前动作的子步。

## 完整运行评分与执行身份

`libero_score_v2` 使用外部固定的执行请求、输入清单和运行回执，检查全部动作／子步分母、
任务／实体／关节绑定、全部原生目标、观测通道及终态，再输出逐坐标残差。
记录结构有效可以同时伴随数值检查未通过或原生任务失败，三者分别报告。
历史记录保留原始身份，未记录的环境元数据仍然未知。

现有 `libero_trials init-tasks`／`run-task` 入口使用同一累计账本和受控资源约定，
串联原生执行与离线评分。新执行清单在原有包版本之外增加 SciPy 和 llvmlite，
并显式固定 `numerical_environment` 中的 `OPENBLAS_NUM_THREADS`、`OMP_NUM_THREADS`、
`MKL_NUM_THREADS`、`NUMBA_NUM_THREADS`、`NUMBA_DISABLE_JIT` 和 `NUMBA_CPU_NAME`。
每项取字符串或 null；null 表示不设置。执行器在子进程导入前设置或删除相应变量，
原生入口在创建环境前拒绝不匹配，并将变量值写入回执。这些是环境控制项，
不能冒充实测线程池数量或完整二进制／平台身份。

这个要求来自保留的比较失败。在输入姿态和包版本一致时，离线原生观测重建在显式
单线程设置下逐值匹配新相对四元数，在继承默认设置下逐值匹配旧相对四元数。
同时改变两个线程变量只能定位这组配置差异，不能分别确定每个变量的独立作用。
观测阈值没有放宽，原来的比较失败也没有改记为通过。

## 方程与时间归属

在这条固定 Euler 路径中，`mj_step` 返回后的力缓存属于积分前的时间，
更新后的 `qpos`、`qvel` 属于子步终点，两者不能混用。
离线 `libero_dynamics` 不导入引擎，分别重建以下残差：

- 平滑力：`qfrc_smooth = qfrc_passive - qfrc_bias + qfrc_applied + qfrc_actuator + J_com^T xfrc_applied`。
- 驱动传递：`qfrc_actuator = actuator_moment^T actuator_force`，再应用已记录的关节驱动力截断。
- 加速度：`M qacc_smooth = qfrc_smooth`，以及 `M qacc = qfrc_smooth + qfrc_constraint`。
- 约束传递：`J^T efc_force = qfrc_constraint`；逐接触解码力，核对约束映射与摩擦锥表示。
- Euler 速度：`(M + h diag(dof_damping)) (v_after - v_before) / h = qfrc_smooth + qfrc_constraint`。
- Euler 位置：使用更新后的速度推进标量／自由体平移，使用对应角速度积分自由体／球关节四元数。

由于阻尼项存在，保存的 `qacc` 不一定就是更新速度所用的加速度。
压缩惯量按自由度父子树独立展开。残差逐坐标保留：广义力可能混合 N 与 N m，
位置可能混合长度、转角和四元数坐标。本文不定义通用物理阈值或合并的“物理通过”。
具体评测协议须在看到结果前固定适用单位、阈值、参考与不确定性。

在固定版本的 Newton／CG 实现中，`M qacc - qfrc_smooth - qfrc_constraint` 也是原始
目标函数梯度。求解器可以按缩放后的代价改善、缩放后的梯度、线搜索失败或迭代上限停止，
所以原生 `tolerance` 不是该残差的逐坐标上界。超过冻结诊断阈值本身不能证明积分或
记录器错误；具体运行的停止原因仍需要对应的求解器观测。

时间与方程语义依据固定版本的[前向计算／积分源码](https://github.com/google-deepmind/mujoco/blob/2.3.7/src/engine/engine_forward.c)
及[惯量／接触辅助源码](https://github.com/google-deepmind/mujoco/blob/2.3.7/src/engine/engine_support.c)。
梯度与停止规则见固定版本的[求解器源码](https://github.com/google-deepmind/mujoco/blob/2.3.7/src/engine/engine_solver.c)。

## 物体受力与求解器观测

新 `physics-model.json` 使用 schema 2，保留物体／根节点／自由度归属、主惯量及其姿态、
空间运动轴及其导数、空间速度／惯量缓存、原生平均惯量归一化量和求解器选项。
离线物体计算使用**积分前速度**，不使用步进后原生数据中已经更新的 `qvel`，
也不调用引擎的前向或逆动力学计算。

空间向量在各运动树的质心处采用世界朝向、角／线顺序。离线 Newton–Euler 计算
重建 `I a + v ×* (I v)`，减去已定位的接触与外加物体力，再累计子节点；
分别校验空间惯量、空间速度和投影到自由度上的物体作用力。
投影中明确保留关节驱动、被动力、直接广义外力、非接触约束以及转子惯量加速度项。
所得**推算子树净作用力矩**可能含未分离的肌腱、等式约束或被动力，不能称作独立测得的
关节轴承反力。解释各根节点力矩前分别换算到世界原点，不直接混加不同运动树原点的向量。

刚性自由关节树还记录世界质心动量变化与预期冲量，包含接触、重力、物体／广义外力及
Euler 阻尼修正。输出逐分量 N s 误差；旋转质心偏移仍存在离散误差。
自由关节下含活动关节或非零转子惯量时明确标为此指标未准入，不引入通用动量阈值。

求解器只保存本次迭代的有效统计前缀。原生容量固定为 1,000，超过容量时明确报告截断。
无约束时的 `solver_nnz`、未启用的前向／逆向比较缓存可能过期，因此记为不可用，
不冒充零值观测。PGS 不提供原始目标梯度统计；NoSlip 阶段会阻止主求解器梯度与最终
结果的直接比较。原生 API 没有暴露精确停止原因，该字段保持明确未知。

schema 2 模型必须使用另行冻结的 schema 2 协议 `mujoco-2.3.7-euler-body-v2`。
除原有八项指标外，新增 `spatial_inertia`、`spatial_velocity` 和
`projected_body_effort` 的逐坐标界限。惯量分量分别具有 kg、kg m、kg m² 单位，
运动与广义力也保留各自的角／线单位；物体数组按物体优先顺序展平后应用数值界限。
评分器按动作报告物体力矩最大值、自由体质心诊断和迭代数，物理参考与关节反力资格
继续单独验收。历史 schema 1 记录仍使用原来的八项协议读取；当前执行要求新协议。

坐标语义核对依据为固定版本的[物体动力学源码](https://github.com/google-deepmind/mujoco/blob/2.3.7/src/engine/engine_core_smooth.c)
和[空间代数源码](https://github.com/google-deepmind/mujoco/blob/2.3.7/src/engine/engine_util_spatial.c)。

## 无损存储布局

存储 schema 2 将所有数值数组按 C 顺序写入单个字节缓冲区，另用 JSON 保存形状、
带字节序的 dtype 和遍历引用，从而减少逐数组 ZIP/NPY 头部。读取时拒绝缺失、别名、
未引用数组及截断或多余字节，恢复独立可写数组，保留正负零、NaN 载荷等数值位模式。
旧存储 schema 1 继续可读；存储版本与物理模型、评分协议的版本分别管理。
候选通过 86 项相关回归。五条完整参考序列（1,006 个动作、25,150 个子步）已全部完成
无损转换和完整重评分，除了显式派生的运行回执哈希，全部字段与评分完全一致。
子步文件从 1,837,228,156 降至 442,665,669 字节，减少 75.91%；原始归档保持不变，
转换副本显式记录离线存储变换来源。这是该批次的实测体积，不是通用容量或原生吞吐结论。
