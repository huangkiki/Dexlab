# 夹持残差：数值闭合改善，滑移依然存在

[English](pinch-impulse-results.md) · [冻结协议](pinch-impulse-protocol.zh-CN.md) · [全部指标与成本](evidence/pinch-impulse/results.json)

六个新诊断工况各执行一次，均满足预先声明的分解检查。两个容差 1e-10 基线与 v0.45.0 已发布轨迹匹配（每个状态分量误差不超过 1e-12）。这证明新增观测复现了这两个工况；不撤销原六个临界记录的拒绝结论，也不代表物理保持通过。

## 结论

临界承载 R=1 的平动冲量残差定位到 `h*(M*qacc-qfrc_smooth-qfrc_constraint)`。停止容差从 1e-6 收紧到 1e-10、1e-14 时，其峰值从 1.234e-6 降至 1.240e-8、1.245e-10 N s；积分项仍约 1.4e-20 N s。因此，记录的速度更新与原生加速度一致，差异主要处于原生加速度／力平衡中。固定其他条件的容差干预支持本夹具的求解精度敏感性，不等于引擎缺陷或普适容差建议；具体触发哪条停止分支仍未由这些观测证明。

运动变化很小：R=1 加载一秒分别下滑 1.99546、1.99456、1.99455 mm；R=2 也约 1.99455 mm。全部六例峰值速度仍约 2.011 mm/s，超过原 1 mm/s 保持阈值。数值力平衡变好没有消除软接触滑移。未改阈值，也未用新记录替换旧结果。

## 复现、成本与边界

官方 MuJoCo 3.15.0 CPU FP64；唯一批次前冻结源码 `c5d70fd80fbe9d1a6386e2cbb16240a649cae361`。六例批次 0.227565 s，受限服务 1.259 s；评分服务 0.782 s，独立环境安装 19.075 s，版本／wheel／测试资格 32.242 s。资格检查含 30 项针对性测试（1.613 s），没有物理步进。准备、控制、原生步进、观测和序列化逐例成本在 JSON 中。这些短时成本仅作观察，不排名。

强制 16 GiB／两核配额／128 任务／零 swap／1800 s，实测桌面内存与磁盘余量，独占研究窗口；物理期间无传输或无关哈希。软件发布回归独立记录于 Release 验证附件。

解压下方原始归档（含两个原基线 trace），在 v0.45.1 checkout 的安装环境执行：

```bash
python -m dexlab.pinch_impulse_score --input /data/extracted/batch1 \
  --evidence docs/evidence/pinch-impulse --baseline /data/extracted/baseline \
  --output /data/new-scores.json
python scripts/analyze_pinch_impulse.py --input /data/extracted/batch1 \
  --scores /data/new-scores.json --output /data/new-figures
```

评分不运行原生物理。哈希绑定观测与可信协议，不能对恶意伪造证明真实性。合成负例覆盖缺观测、加速度／状态／载荷篡改、编译质量／源码／文件错误及基线不匹配；数值诊断拒绝仍继续保留其他工况。

本导向夹具使用合成摩擦、显式预加载辅助，结论限于声明配置，不是真实材料、机器人策略或普适引擎精度。下一步可研究有限尺寸手指；如需精确算法归因，应另立求解停止诊断协议。v0.45.0 原拒绝记录完整保留。
