# BladeMaster comparison GIFs

These GIFs are presentation copies of comparison videos published by the
BladeMaster authors. They are not DexLab physics runs.

- `blademaster.gif`: converted from
  <https://jango6324.github.io/assets/blademaster/videos/10-cressim-mpm-comparison-blademaster-30fps.mp4>.
- `cressim-mpm.gif`: converted from
  <https://jango6324.github.io/assets/blademaster/videos/10-cressim-mpm-comparison-cressim-mpm-30fps.mp4>.

Both use 8 fps, 640-pixel width and a 96-colour palette. The source pages and
measurement limits remain in `docs/site/{zh,en}/cutting-comparison.md`.
