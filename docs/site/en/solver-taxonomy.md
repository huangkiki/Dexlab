# Solver configuration roles

The comparison unit is a versioned core, runtime path, physical model and numerical configuration. MuJoCo PGS/nonlinear CG/Newton are alternative constraint methods; SuperDex Newton and GMRES are outer and inner methods. Cloth implementations, contact models, approximations, integrators and update budgets are not peer algorithms.

The [complete bilingual role guide](https://github.com/huangkiki/Dexlab/blob/main/docs/solver-taxonomy.md) explains each engine, source evidence, system-profile selection versus algorithm attribution, and unresolved identities. The [display vocabulary](https://github.com/huangkiki/Dexlab/blob/main/docs/solver-taxonomy.json) never changes recorded scores, counts or qualification.
