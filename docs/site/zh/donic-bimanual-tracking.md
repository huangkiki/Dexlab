# DONIC 的双手跟踪分，能看出交接成功吗？

假设左手托着杯子，右手接住后把它移开。交接时如果左手已经松开，右手还没托住，杯子会短暂失去支撑。右手后来补救，两手在整段里的平均姿态误差仍可能很小。DONIC 的研究价值在于让同一个控制器学习不同参考中的双手分工。对 DexLab 来说，还有一个更具体的问题。**跟踪分已经过线时，哪条证据能说明交接也完成了？**

## 两手怎样学会跟同一条参考

控制器提前知道双手和杯子下一步该去哪里。它根据当前状态修正参考动作，同时看杯子的位置、旋转和速度。参考要求左手先支撑时，左手先收到接触奖励；两手都应触杯时，两边各算；左手应释放后，左手退出这项接触计分。物体运动一直参与奖励。奖励按参与手平均，一只手失去接触时另一只手仍有独立的学习信号。[论文 §4.2–4.3](https://arxiv.org/html/2610.29997v1#S4.SS3)

训练还做了两件事。先把同一条参考里的 PPO 优势减去它们的均值。比如 −5 和 −3 变成 −1 和 1，差距保持 2，较好的动作仍排在前面。再把专家或共享策略已经成功执行、且重放仍达到物体位移和所需抬升条件的动作收进示教库，供另一批行为克隆更新使用。示教回收沿用 DexTrack，论文将它与逐手接触监督和片段中心化结合起来。[DONIC §4.4、附录 C.3–C.4](https://arxiv.org/html/2610.29997v1#A3) · [DexTrack](https://arxiv.org/abs/2502.09614)

## 成功率衡量了什么

作者在 Isaac Gym 跟踪单个刚体。公共训练池 1,845 段，同一个冻结策略在已见物体的新轨迹上通过 **46/53（86.79%）**，在留出物体的轨迹上通过 **94/164（57.32%）**。较强适配基线 Dexplore-bi 对应 **5/53** 和 **19/164**。加上 BiHOI 的 1,575 段参考，分别提高到 **47/53** 和 **98/164**。这个增量同时改变规模和分布，无法单独估计“双手接触更多”带来的收益。整数分子按分组大小和表中百分比还原。项目页说明 DexTrack-bi 使用自身的参考转换和场景。[论文 Table 2](https://arxiv.org/html/2610.29997v1#S5.T2) · [项目页对照](https://ropedia.github.io/DONIC/#compare)

论文的 SR 按整段平均误差判定，两只手各自和物体一起过阈值，整段才算通过。Comp 逐帧判定，恢复后的帧也可以计分。去掉片段中心化后，留出物体 SR 降到 48.17%；仅用净力估计接触而移除 3 cm 距离条件时，降到 48.78%。后一项消融保留原物体奖励与逐手汇总。两组留出成绩衡量有参考条件的仿真跟踪。自主任务、未见操作类别和真机表现需要各自的评估。[论文附录 D.2–D.6](https://arxiv.org/html/2610.29997v1#A4)

## 交接时查什么

DONIC 的接触代理要求指尖净力大于 0.5 N，且距物体表面小于 3 cm。手指如果在杯面旁边碰了桌子，桌面反力也可能达到阈值。用碰撞体对可查是否接触了杯子。杯子有没有被托住，再看接触传力方向、冲量和杯体随后怎样移动。[论文 §4.3、附录 C.2](https://arxiv.org/html/2610.29997v1#A3.SS2)

DexLab 可以先固定一条扶持、接手、释放的参考和一个合格对照，再检查两条设计反例。第一条让指尖在物体附近只碰桌面，验证评分能否识别接触对象归错。第二条让左手提前松开，在右手承担支撑之前检查杯体是否出现下移，验证整段跟踪达标时能否同时报告交接失败。三条轨迹都应在同一时轴上报告跟踪误差、接触体对和阶段结果，缺观测的判断应保留为不可判定。可以先查现有记录能提供什么，再使用明确标注的合成数据检查规则。这是离线验证提案。[DexLab 讨论 #423](https://github.com/huangkiki/Dexlab/discussions/423) · [既有评分语义讨论 #302](https://github.com/huangkiki/Dexlab/discussions/302)

## 可核查的实现与数据
