# Chaos、Bullet 与 SOFA 的斜面对照

三个后端各完成九个原工况和一个禁碰撞负对照。**Chaos 通过三个名义零摩擦工况，Bullet 通过两个静止工况和一个名义零摩擦工况，SOFA 的九条记录通过动量核对，均未通过完整物理判据。** {ref}`九引擎矩阵与并排曲线 <incline>`

## 对齐了哪些条件

使用 40 mm、64 g 的均匀方块，从底面贴合斜面、速度为零开始。重力为 9.81 m/s²，记录 2 s。三种工况为 15°、μ=0.5 静置，35°、μ=0.5 滑动，以及 15°、μ=0 的名义无摩擦滑动。每种工况跑 2、1、0.5 ms 三档步长。斜面原清单的九例、评分窗口和阈值均沿用。新增负对照不进入九例分母。 [原斜面协议](https://github.com/huangkiki/Dexlab/blob/main/docs/incline-comparison-protocol.zh-CN.md)

- **Chaos** 每个 Editor 帧手动推进一次世界，在求解器回调中读取真实时间、位姿和速度。接触冲量包含速度冲量与位置修正除以实际步长两项，并逐步核对动量。记录接触点的实际静摩擦与动摩擦参数。
- **Bullet** 使用解析平面，读取各接触点法向以及两条切向力，按完成步区间求总冲量。斜面和方块的摩擦参数分别为 1 和目标 μ，有效乘积来自原生组合机制。绑定能读回物体参数。
- **SOFA** 使用两个有向盒碰撞体，约束响应采用 `FrictionContactConstraint`。读取求解器逐行乘子与刚体世界坐标下的 `lambda`，按实际步间隔换算并核对动量。约束行数用于检查支撑记录，碰撞点数未测。摩擦读回来自接触管理器。

Chaos 和 SOFA 使用有限斜板，方块运动范围始终在斜板上表面范围内。共同穿透指标由原生位姿和解析斜面重建。每个配置保留自己的接触律、碰撞余量、迭代与精度，结论限定在这些配置。正例的动量一致性门槛沿用 1e-7 N·s。

## 首次失效发生在哪里

### Chaos

| 工况 | 第一步到结果 |
| --- | --- |
| 静止，2 ms | 第一步有 −0.149 N 切向力。约 0.034 s 转角超过 0.01 rad，0.068 s 漂移超过 1 mm，最终沿斜面移动 1.461 m。 |
| 静止，1 ms | 第一步法向约 0.606 N，切向接近零。0.028 s 漂移超过 1 mm，最终移动 5.081 m。 |
| 静止，0.5 ms | 第一步同样有法向支撑，切向接近零。0.028 s 漂移超过 1 mm，最终移动 5.079 m。 |
| 滑动，2 ms | 加速下滑后，第 811 步（结束时刻 1.622 s）首次超过动量残差门槛。全程最大残差 1.104e-7 N·s，记为无效。 |
| 滑动，1 ms | 第一物理步有法向支撑，切向近零。下滑加速到第 1597 步（1.597 s）首次超出一致性门槛。最大残差 1.102e-7 N·s，记为无效。 |
| 滑动，0.5 ms | 第一物理步有法向支撑，切向近零。下滑加速到第 3175 步（1.5875 s）首次超出一致性门槛。最大残差 1.036e-7 N·s，记为无效。 |

在两档较小步长下，静止组的 0.5 摩擦参数实际读回正确，但评分窗口的切向力绝对值低于 1.2e-8 N，和零摩擦对照几乎重合。问题已定位到设定摩擦后没有读到有效切向支撑。要区分接触锚点、摩擦迭代和阶段选择，需要在相同场景记录首步各阶段的切向冲量。三条滑动记录的越界发生在速度增大之后，舍入只能解释其中部分残差。需要同一区间的求解速度与写回速度来进一步区分。

### Bullet

| 工况 | 支撑变化与后果 |
| --- | --- |
| 静止，0.5 ms | 方块基本停住，仍有三点接触。评分窗内法向力在 0.600–0.613 N 波动，总力 RMSE 0.01446 N 超过 0.01 N。 |
| 滑动，2 ms | 从贴面静止到下滑，0.242 s 转角超限。评分窗口仅一条接触记录每步，法向力在 0.128–1.180 N 波动，总力 RMSE 0.34731 N。 |
| 滑动，1 ms | 0.335 s 转角超限。评分窗口每步一条接触记录，法向力 0.131–1.166 N，总力 RMSE 0.35226 N。 |
| 滑动，0.5 ms | 转角满足判据，总力 RMSE 0.33972 N。评分窗口支撑力 0.135–1.398 N，力波动在更细采样下仍存在。 |
| 名义零摩擦，2 ms | 方块接近解析滑动轨迹。1.180 s 开始在评分窗口读到超出 0.01 N 的单步总力偏差，最终 RMSE 0.01026 N。 |
| 名义零摩擦，0.5 ms | 方块接近解析滑动轨迹。评分窗口的法向力在 0.147–1.066 N 变化，总力 RMSE 0.08128 N。 |

失败最先出现在支撑力波动或转动，状态与冲量对账仍通过。下一判因门槛是把接触点位置、接触持续步数和法向／切向冲量绑定到同一时间区间，检查波动是否随支撑点切换发生。

最早的失效在接触支撑与静止保持。约束行与状态到同一物理步的动量账目通过。下一步需要读回 OBB 接触位置和约束间隙，区分接触生成、约束响应和接触阈值的贡献。表中单步偏差用于定位起点，整体力判据使用评分窗口的 RMSE。

### 禁碰撞负对照

三个方块都穿过斜面并且没有接触记录。Bullet 与 SOFA 通过逐步自由落体速度核对。Chaos 在 1.431 s 首次超过 1e-4 m/s 的严限，2 s 时竖直速度约 −19.61966 m/s。按厘米单位用逐步单精度累加复算后，与原生全程速度的最大差为 2.4e-9 m/s。该负例保留为原严格检查无效。
