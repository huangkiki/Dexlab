# 从合格抓持中预测接触丢失

本入口先检验一个比策略优化更小的问题：**预测器能否判断物体将移到哪里、哪个手指将丢失接触？** 输入是已有六个 [Wuji v4 合成回合](wuji-contact.md)，包含 open/no-contact/zero-friction 失败对照。目前没有合格学习模型或新原生干预结果。

六回合离线报告已完成：原始完整性和数值平衡检查全部通过，所选数据没有重复副本，实现另通过 14 项解析回归。预测只读取起点状态和上一步已完成的接触观测，未来标签只参与评分。已有视频和重叠窗口不会增加独立重复次数，也不是新的留出回合。


## 实际基线误差

100 ms 时域下，每回合有 100 个起点，范围为 1.20–3.18 s；目标时点可延伸至 3.28 s，包含释放／卸载刚开始的部分。这些来自单次开发回合的窗口相互相关，不是重复试验。

| 源案例 | 保持位置 RMSE（mm） | 常速位置 RMSE（mm） |
| --- | ---: | ---: |
| hold-release | 0.0491 | 0.0221 |
| unload-index_finger | 0.0484 | 0.0181 |
| unload-thumb | 0.0505 | 0.0232 |
| open | 1342.0424 | 49.2953 |
| no-contact | 1342.0424 | 49.2953 |
| zero-friction | 1326.2571 | 49.2953 |

常速在这里降低了短时位移误差，但两种接触保持基线均不能预报丢失。在命令释放／卸载阶段、100 ms 时域下，三个抓持案例分别有 5/6、6/6、5/5 个食指／拇指丢失窗口，两种基线全部漏报。这些窗口互相重叠，不是独立物理事件次数。常速也忽略重力：自由落体对照约 49.2953 mm 的误差符合半隐式参考式 `g*h*(h+dt)/2`，其中 `h=0.1 s`、`dt=0.0005 s`、`g=9.81 m/s²`。

[逐阶段、手指、时域的完整数据](https://github.com/huangkiki/Dexlab/blob/main/docs/evidence/contact-response/baselines.json) 同时保留原任务评分和预测诊断。SHA-256：`ae888c5cd970f6f9ab694741203484c30c00a049ab7c92be37350b55ca1d0c98`。独占窗口复算得到逐字节相同的报告；这只验证离线可复算性，不是新的原生重复。原生因果响应和控制收益仍未评价。

## 复算离线诊断

完成 [Wuji 证据包下载](wuji-contact.md) 后，将新入口加入稀疏检出，复用相同隔离离线依赖：

```bash
git sparse-checkout add demos/contact-response
uv run --offline --no-project --isolated --python 3.12.12 \
  --with-requirements demos/wuji-contact/offline-requirements.txt \
  python demos/contact-response/baselines.py \
  --bundle downloads/wuji-contact-v1 --output response-baselines.json
```

导入器核对固定 manifest／数据哈希、独立数值一致性和完整回合指纹，在评价前分离复制／重压缩副本。全部数据仅作诊断，不拟合模型，不宣称泛化验证。

| 诊断 | 测量内容 | 限制 |
| --- | --- | --- |
| 保持／常速 | 20、100、200 ms 的世界位置和姿态误差 | 两种基线均不使用动作，也不能预见接触切换 |
| 接触保持 | 各手指法向载荷是否超过原有 0.02 N 阈值 | 相向载荷可在净力中抵消；未报告接触不是正间隙测量 |
| 建立／持续／丢失／切换 | 终点混淆计数和整个预测窗口的事件 | 重叠窗口相关，按整回合分别报告 |
| 完整可见前缀 | 位置、角度、速度、控制、外部输入及原生接触按各自单位比较 | 兼容前缀不证明因果响应或隐藏求解器状态相同 |

外力辅助准备与无支撑保持分别记录。预测起点 `i` 使用求解前姿态／速度，最新可用接触来自已完成的 `i-1` 步。常角速度在记录的局部坐标中积分，不把四元数分量差当作角度。

前缀命令要求后续协议提前冻结每组字段的容差和依据。历史记录不能证明新进程／完整模型身份或合格重复波动范围，所以因果响应仍一律保留 `UNIDENTIFIED`。[完整命令与观测约定](https://github.com/huangkiki/Dexlab/blob/main/demos/contact-response/README.zh-CN.md)。
