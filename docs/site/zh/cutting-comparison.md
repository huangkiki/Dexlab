## 原站对比在检验什么

[BladeMaster 项目页](https://jango6324.github.io/blademaster/#comparison)及[论文 v2，IV-A / Fig. 5](https://arxiv.org/abs/2609.27342v2)比较了两次平行切割后的历史保持：撤刀后，仅给左块一个向左的初速度，观察中、右块是否被共同网格速度带动。两段参考视频均由 BladeMaster 作者发布，其中 CRESSim-MPM 是作者对 [Ou 与 Tavakoli (2025)](https://arxiv.org/abs/2502.18437) 方法的比较结果。

| 测量事件与指标 | BladeMaster¹ | CRESSim-MPM¹ | DexLab² |
| --- | ---: | ---: | ---: |
| 第一刀半深：平均切口宽度（mm） | 0.654 | 4.059 | 0.496（0.82 s） |
| 两刀撤出：中间块体积收缩（%） | 0.506 | 8.746 | 2.509（4.00 s） |
| 刀面推动后：左块 x 位移（mm） | 不同输入 | 不同输入 | -11.128 |
| 同一窗口：中／右块 x 位移（mm） | 不同输入 | 不同输入 | -0.038／-0.015 |
| 刀推阶段：净向左接触冲量（N·s） | 不同输入 | 不同输入 | 0.105801 |

**末尾施力方式不同：** 作者参考片给左块初速度；该历史 DexLab 记录由刀面接触向左推，材料没有直接速度增量。前两行切割指标仍可并列阅读，后三行仅说明 DexLab 刀推动作，不能作为相同输入的三方对比。

¹ [BladeMaster 原站／论文 Fig. 5](https://jango6324.github.io/blademaster/#comparison)报告的数值，包括其 CRESSim-MPM 对照。² [DexLab 保存状态的事件测量](https://github.com/huangkiki/Dexlab/blob/main/demos/tofu-knife-push/evidence.json)，5 mm 网格、0.25 ms 步长、0.5 mm 刀片；位移窗口为 4.00–7.00 s；刀接触冲量积分窗口为 4.00–6.60 s。半深事件为 0.82375 s，表中取最近保存帧 0.82 s。切口采用材料面仿射估计，体积采用中块内部四面体；收缩量等于负的体积相对变化（-ΔV/V₀）。三列为**已报告／实测数值并列**，原作完整配置与采样口径仍待[对齐](https://github.com/huangkiki/Dexlab/issues/200)，尚非同条件精度排名。

## 后续同条件比较协议

1. **锁定同一个问题。** 两次切割后，第一条切面的机械分离能否保持？在试验前冻结块体尺寸、材料参数、粒子采样、刀片几何、切割轨迹和接触模型；先解决原站未公开的参数，不从画面猜数值。
2. **对齐事件。** 保存第一刀半深、第一刀撤出、第二刀撤出、单块初速度施加和固定时长后的状态。同步时间轴仅用于共享输入的运行，不能通过拉伸视频暗示同等速度或成本。
3. **分别量化。** 在同一材料坐标带测平均切口及分布；用声明的体积估计方法测中块收缩；记录所有块的质心位移、动量与外部冲量。切面看起来分开不能替代连接图验收。
4. **保留反例。** 未切、仅部分切、撤刀后移除历史标签的消融；核对半步长与更细采样的敏感性。失败、无效记录和未运行方法都保留。
5. **先完成资格，再出排名。** 每个实际实现需有源码/二进制版本、同输入记录、独立评分、预算和原始数据；作者视频只作参考。目前尚未执行同条件三方比较，不作优劣排名。

这是本项目后续比较的可复用检查顺序，实际新增基准仍需单独冻结协议与资源预算。当前页面先交付三列视频和明确的来源边界。
