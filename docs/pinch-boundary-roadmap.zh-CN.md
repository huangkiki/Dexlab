# 统一驱动与夹持失效边界：开发路线

## 目标与决策

在共同夹具和外部 PD 下，研究逐指驱动力限额对保持、释放及初态、步长、重复运行敏感性的影响。首批交付 MuJoCo、Genesis CPU FP64 的静态曲线、逐例结果、原始记录与中英报告；保留六引擎完整状态表。首轮不开发交互回放器，数据保留后续回放所需状态与时间语义。

- 共同夹具以现有 Genesis 有限夹具为来源：40 mm、64 g 方块、两个有限夹指、升降架和水平桌面。固定质量/惯量、关节轴、限位、初态、碰撞对及四秒夹持—抬升—保持—释放轨迹。MuJoCo 建立对应有限夹具；历史导向夹面和旧 Genesis 原生驱动结果不混入统计。
- 自由度顺序为升降、左指、右指。`u = clip(Kp * (q_ref - q) - Kd * qdot)`，`Kp=[1000,500,500] N/m`、`Kd=[50,20,20] N·s/m`。升降限额 ±50 N，各指使用工况的对称限额；无目标速度前馈或重力补偿。
- 控制周期 1 ms；物理步为 1、0.5、0.25 ms，整数时钟驱动更新、步间保持输出。两引擎使用自己的状态闭环。MuJoCo 单位传动比力执行器，Genesis 直接关节力控制；隐藏位置驱动、被动阻尼和附加关节惯量须关闭并核实。
- 先准入官方最新稳定兼容组合，再冻结版本、源码、原生二进制、依赖、接触及求解配置和有效读回。名义摩擦系数相同不表示材料等价；算法身份不能由当前默认值推断。

## 待实现接口与记录

现有 `python -m dexlab.pinch_boundary list-cases` 仅展开协议身份。后续实现同模块的 `qualify / run / score / report / check-campaign`；这些入口目前尚未实现。输入为冻结清单与工况编号，运行、离线评分和报告互相独立。A 定义最小必要的数据约定，B/C 分别实现；不为预留扩展建立通用框架。

每个物理步分别记录步前/步后状态、控制更新时刻、目标、限幅前后命令、原生执行器力，以及接触点身份、位置、法向、力和所属时刻；同时保存求解状态、警告、成本和首个失败位置。命令、原生执行器力、接触力分开。不可观测字段保留缺失及原因；必要观测无法核验时阻止相应后端准入，不能复制命令充当测量。协议、模型、运行代码、评分器和原始数据绑定哈希。

## 批次与预算

| 维度 | 已采纳需求 |
|---|---|
| 后端 | MuJoCo、Genesis；CPU FP64 |
| 每指限额 / N | 0.2、0.4、0.45、0.5、0.55、0.6、0.65、0.7、0.75、0.8、10 |
| 初始横向偏移 / mm | −2、0、+2 |
| 物理步长 / ms | 1、0.5、0.25；控制周期固定 1 |
| 重复与时长 | 每条件 3 次，相同种子、独立进程；每次 4 s |

正式回合 `2 × 11 × 3 × 3 × 3 = 594`，对应 198 个固定条件，不推断总体成功概率。另有 24 个对照：18 个张指（两后端 × 三偏移 × 三步长），6 个名义零摩擦（中心初态、10 N，两后端 × 三步长）；记录摩擦下限、组合规则及扭转/滚动项。资格最多 32 回合，包含已知无接触力、控制模式和 Genesis 原生驱动到外部驱动的桥接，桥接单列。

**本批次实验累计最多 6 小时、700 次启动，单进程最多 30 分钟；没有新增云资源。** 包含资格、桥接、正式、对照及重试的初始化、编译、观测与写盘。开发调试与提交回归另记账，沿用原资源限制；不能把批次尝试重新标为调试以逃逸预算。最多 650 次基础启动（594+24+32）；资格全部用满时，额外启动最多剩 50 次。

B/C 须交付可恢复账本：保存所有尝试、完整进程墙时、原因、剩余额度和输出。启动前检查额度，超时主动终止，恢复不清零、不重复领取；每次超时不超过剩余全局时间或 30 分钟。仅基础设施/记录故障可以限次重试，真实物理失败不得重跑到成功。资格阶段用实测成本评估全矩阵预算，不能将预算当完成承诺。耗尽时剩余项为 not-run，交付阶段报告和恢复条件；不缩小矩阵宣布完成。

## 评分与完成条件

[A 协议](pinch-boundary-protocol.zh-CN.md)已固定以下要求，B/C 负责实现与核验：

- 保持窗口 2–3 s（含端点）：方块质心始终 ≥60 mm、两指有效接触、其他竖直支撑 ≤0.01 N。释放窗口 3.8–4 s（含端点）：质心 ≤30 mm、逐接触点夹指力模长之和 ≤0.01 N。明确有效接触定义、坐标与采样时刻。
- 保留 1 mm 穿透预算、`1e-8 N` 接触力账一致性、5% 重力冲量残差。力账阈值检查逐接触力与物体净接触力，不替代命令/原生执行器输出或已知力动力学资格；A/B 单独定义并核实这些检查及容差。
- 方块—平面用解析几何；方块—有限夹指使用完整 OBB 检查，并明确定量穿透定义；使用同一状态时刻。原生接触深度单列。
- 分别报告记录完整性、数值状态、穿透、保持、释放、相对夹具位移/速度、实际法向载荷、接触冲量和成本。首次阈值违规不等于真实滑移起始。
- 覆盖 PD/限幅/方向/三步长控制时钟；无接触已知力与原生输出；接触力符号、坐标变换、错时/缺步；旋转与边缘交叠；坏哈希、重复/缺失工况、损坏记录、数值中止及正常任务失败；张指与名义零摩擦对照。异常保持先查卡托与配置，不放宽阈值。
- 验证中断恢复不重复领取、预算不重置、错误哈希拒绝复用、失败不覆盖和图表可从冻结数据重建。代码交付继续执行仓库完整回归。

保留每条曲线三次重复。结果支持单调关系时才报告“测试网格过渡区间”；反转/分歧报告通过区段与混合结果。0.8–10 N 未采样区间不能插值宣称精确边界。

`check-campaign` 分别检查覆盖、证据有效性和任务结果，不要求全部抓取成功。资格通过后的物理失败、穿透超限和具有可复算有效前缀/首个失败位置的数值中止属于结果；未运行、无法恢复的损坏记录、基础设施重试耗尽不构成完整批次。正式完成要求 594+24 项全部有可核验实验终态，所有尝试保留、独立复算成立、每项数字/图表可追溯。否则只能交付阶段报告。
