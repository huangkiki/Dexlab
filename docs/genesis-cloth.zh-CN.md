## 源码核对

官方 [Genesis 1.4.3](https://github.com/Genesis-Embodied-AI/genesis-world/releases/tag/v1.4.3)，源码版本 `216a708e06124595521a9d36a51fae5393fd4ff8`，准入时仍为最新稳定版。
- `engine/materials/PBD/cloth.py` 的 rho 是 kg/m²，总质量由面积计算。拉伸与弯曲柔顺参数文档单位分别为 m/N、rad/N，不能直接当成已标定布料的连续材料参数。
- `engine/entities/pbd_entity.py` 按粒子尺寸重新网格化，必须读回实际顶点、拓扑、等分粒子质量；输入网格数不是实际分辨率。
- `engine/couplers/legacy_coupler.py::_func_pbd_collide_with_rigid_geom` 以粒子中心到刚体的有符号距离和半粒径判断接触。位置修正改变速度，再将相反动量变化施加刚体；源码公式还不能证明实际双向耦合。该分支明确未实现切向摩擦，不能凭摩擦参数存在宣称布料/桌面库仑摩擦。
- `engine/solvers/pbd_solver.py` 自接触是带静止距离排除的粒子对分离，不保证三角面或边连续不穿越。域边界可能形成隐藏地面，负对照下界必须低于预计轨迹。

## 首批冻结开发协议

单个 CPU FP64 执行者，官方原生代码不改，计时不渲染。最多6条轨迹，总时限1800秒。三场景各重置重复两次：平面耦合开启且摩擦0.01、开启且摩擦0.5、关闭耦合且摩擦0.01。每场景一起设置平面普通/耦合摩擦及布料静/动摩擦，其余不变。这是参数作用诊断，不是同物性标定。

自行生成边长40 mm、输入5×5顶点的三角薄面，不下载资产。原生重网格化后保存实际顶点、三角面、边静止长度、质量和参数数组。面密度0.2 kg/m²；粒径8 mm；初始高度20 mm；初始统一x速度0.2 m/s；重力(0,0,-9.81)m/s²。步长2 ms、单子步、150步共0.3秒；拉伸迭代4、弯曲1；柔顺1e-7/1e-5，松弛0.3/0.1，空气阻力0。不固定、不附着、不加控制器，初始化后不注入状态。域下界z=-1 m，负对照自由落体末态约-0.424 m，远离下界。

记录初态和每一步粒子位置/速度、实际原生参数和可用的刚体反作用读数。须核实接口实现，不能把只含刚体接触的读数称PBD耦合力；缺原生力就记缺测。动量推导力只作独立诊断，不冒充原生真值。分别记录初始化/构建、步进、观测、评分耗时，保留失败和中断。

冻结判据：记录完整有限；有支撑薄面最低z≥-0.5 mm，末0.1秒质心高度相对4 mm半径误差≤0.5 mm；关闭耦合必须失去支撑，并与离散半隐式自由落体位置误差≤0.1 mm、速度误差≤0.001 m/s。重置初态及全轨迹按1e-9 m/1e-8 m/s比较，有偏差完整报告。给出有符号水平位移/速度及高低摩擦差异，不把必须产生摩擦效应作为诊断有效条件。源码预期该耦合不含切向摩擦，实际行为仍由原生运行确认。

## 开发实验结果（非完整准入）

已用逐文件核验的官方 1.4.3 wheel 完成预登记的六条轨迹。25 个输入顶点经原生重网格化后成为 38 个粒子。两组启用耦合的条件均停在 4 mm 高度，顶点未穿过平面。关闭耦合后符合离散自由落体，最大高度误差 1.15e-14 m，排除了域边界充当支撑的情况。各条件两次重置后的完整位置、速度记录完全一致。

声明摩擦参数从 0.01 改为 0.5，记录轨迹差异为零：水平方向均移动 60 mm，末速度仍约为 0.2 m/s。这与原生 PBD/刚体路径未实现切向摩擦的源码判断一致。**诊断通过不等于摩擦夹布通过**，不能继续把调大此参数当成已验证的夹持方案。

受限进程共用时 68.981 s，包含来源核验与初始化。三次构建分别为 22.477/3.083/2.914 s；每条 150 步循环耗时 4.528–5.317 s。这是单执行者诊断耗时，不能用于跨引擎速度排名。原始记录与冻结源码已打包，入口见下文。此前一次调度在进入物理前因系统 Python 缺少 `hashlib.file_digest` 失败，已改用既有 Python 3.12 环境，并保留失败记录。

## 自由刚体动量协议

下一批四条轨迹使用自由的80×80×10 mm板（密度15.625 kg/m³，读回质量1 g、六个自由度），零重力、无桌面、固定点或驱动器。布从20 mm高度以vz=-0.1 m/s开始，其余网格、柔度和步长保持不变。耦合启用/关闭各重置两次，每次150步。根据实际粒子质量与速度、刚体质心质量与速度计算总线动量，最大残差应≤初始动量模长的1% +1e-8 kg m/s。正对照要求板向下获得的动量和布反向变化均至少达到初始布动量的10%。关闭耦合时要求板位移≤1e-9m、速度≤1e-8m/s，布速度变化≤1e-8m/s。重置容差仍为1e-9m/1e-8m/s。该守恒参考不证明角动量或原生力读回。总时限1800s，初始化后不写状态、不加隐藏连接、不事后放宽阈值。

### 自由刚体结果：同一步守恒未通过

四条轨迹全部运行完毕，受限进程耗时33.257 s，重置重复完全一致。关闭耦合时板保持静止、布速度不变，负对照通过。启用耦合后，布的z动量改变+3.2e-5 kg m/s，板最终获得-3.2e-5 kg m/s；但布在第56步变化，板到第57步才变化。同一时刻的总动量最大残差为3.2e-5 kg m/s，超过预先冻结的3.3e-7容差，因此**验收失败**。最终残差约1.76e-19不能消除瞬时失败。

事后把刚体速度错开一步，诊断残差降至约1.76e-19，支持一步耦合延迟的解释，但不以该指标替代验收。官方执行顺序先做刚体的耦合前积分，再做legacy耦合；`rigid/abd/misc.py::func_apply_coupling_force`把反力累积到待处理的`cfrc_coupling_*`字段，与实测2 ms延迟相符。未修改原生源码；直接刚体接触力字段仍不能当作已验证的PBD反力。该结果证明有延迟的双向交换，不证明同一步动量精度。

## 冻结的单步响应敏感性实验

独立的36格全因子实验：粒径12/8/6 mm、步长4/2/1 ms，分别启用/关闭拉伸与弯曲。零重力、零初速度，无刚体或固定点。只在初始化时将x乘1.1（拉伸）或z加0.2|x|（弯曲），基准高度0.2m。官方选项在建场景前拒绝零迭代，失败记录已保留。重新登记后所有格点保持4次拉伸/1次弯曲迭代，用官方支持的零松弛系数关闭约束，仅在相应正对照启用拉伸0.3或弯曲0.1。此次修改前尚无响应结果，验收阈值不变。保持此前面密度、柔度和松弛参数，保存实际静止拓扑、质量、初末状态和原生选项。

独立参考为静止边长和相邻面平直法向。启用约束时要求RMS应变/折角降低>1e-10、质心漂移≤1e-9m；关闭时位置变化≤1e-9m、速度≤1e-8m/s，并保持有限、无退化的几何。保留所有格点。这些最低响应方向检查不证明本构幅值、卸载、长期稳定性或连续体收敛；粒径改变也同时改变接触尺度。评分器用解析平面、均匀拉伸和V折角核验。单执行者，总36步、时限1800s。

## 冻结的驱动夹持／释放协议

初始化实际关节为[0,25.5,25.5]mm，指间隙9mm；0.2s内指令闭合至26.25mm（7.5mm间隙），保持至1s；1–2s抬高80mm，保持至3.2s，随后张开并保留抬升至4s。显式PD先验为kp[1000,500,500]、kv[50,20,20]，力限制±[50,10,10]N、零附加惯量，不称自主学习。

## 复现

使用仓库setup环境，再以`uv pip install --python .venv/bin/python genesis-world==1.4.3`安装可选官方引擎。实验须经`scripts/bounded_run.py`资源准入，使用执行设备自己的既有数据卷和块设备，不得在桌面无界运行。以下是放在受限执行器`--`之后的工作负载命令；每个OUTPUT必须是新目录：

```bash
.venv/bin/python -m dexlab.genesis_cloth_probe OUTPUT
.venv/bin/python -m dexlab.genesis_cloth_coupling_probe OUTPUT
.venv/bin/python -m dexlab.genesis_cloth_response_probe OUTPUT
.venv/bin/python -m dexlab.genesis_cloth_gripper_probe OUTPUT --gravity-compensation
.venv/bin/python -m dexlab.genesis_cloth_self_probe OUTPUT
```

这些都是合成开发工况，不宣称留出材料测试成绩。无需重跑原生实验的离线复核：

```bash
.venv/bin/python -m unittest discover -s tests -p 'test_genesis_cloth*.py'
```

`python -m dexlab.genesis_cloth_replay RECORD.json.gz OUTPUT --prefix gripper`仅根据记录状态重新生成固定视角回放。
